# Criterios de aceptación

El módulo se considera funcional cuando:

1. Registra folio Intelisis.
2. Registra cliente y productos.
3. Maneja estados completos.
4. Imprime etiqueta.
5. Guarda ubicación física.
6. Registra recepción parcial.
7. Registra entrega parcial.
8. Mantiene pendiente hasta completar.
9. Registra contacto.
10. Programa recolección.
11. Genera alerta de 20 días.
12. Maneja cancelación y liberación.
13. Relaciona inventario, CRM, CEDIS y proveedor.
14. Conserva auditoría.
15. No modifica Intelisis.
