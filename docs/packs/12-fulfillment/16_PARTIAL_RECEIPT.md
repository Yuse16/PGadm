# Recepción parcial

## Caso

Llega solo una parte de los productos o cantidades del folio.

## PWA

Debe registrar:

- Cantidad esperada.
- Cantidad recibida.
- Cantidad pendiente.
- Fecha.
- Responsable.
- Evidencia.
- Ubicación de lo recibido.

## Regla

El caso permanece abierto hasta completar o cerrar mediante decisión autorizada.
