# Folios

## Ejemplo observado

`1NOG-######`

## Uso

El folio de Intelisis debe ser la referencia principal del caso.

## Campos

- Folio Intelisis.
- Sucursal.
- Cliente.
- Teléfono.
- Fecha de venta.
- Vendedora.
- Estado.
- Productos.
- Cantidades.
- Fecha estimada.
- Ubicación física.

## Regla

No crear duplicados para el mismo folio sin advertencia.
