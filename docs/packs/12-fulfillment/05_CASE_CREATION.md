# Creación del caso

## Origen

- Venta capturada.
- Producto pendiente.
- Balanceo.
- Pedido a proveedor.
- Recepción parcial.
- Captura manual.
- Importación futura desde Intelisis.

## Datos mínimos

- Folio.
- Cliente.
- Teléfono.
- Productos.
- Cantidades.
- Sucursal.
- Vendedora.
- Fecha.
- Estado inicial.

## Validaciones

- Folio válido.
- Producto exacto.
- Cantidad positiva.
- Cliente relacionado.
- No duplicidad.
