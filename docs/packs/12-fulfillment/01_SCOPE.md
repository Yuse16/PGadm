# Alcance

## Incluido

- Productos separados.
- Mercancía pendiente de conseguir.
- Pedidos a proveedor.
- Backorder confirmado.
- Recepciones parciales.
- Recepciones completas.
- Mercancía lista para recoger.
- Contacto con cliente.
- Entrega parcial.
- Entrega completa.
- Etiquetas imprimibles.
- Alertas por antigüedad.
- Auditoría.

## Fuera de alcance inicial

- Cobro.
- Facturación.
- Modificación directa de Intelisis.
- Firma electrónica con validez legal.
- Optimización de rutas.
