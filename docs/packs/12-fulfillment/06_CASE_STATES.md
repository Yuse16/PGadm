# Estados del caso

## Estados confirmados

1. Pendiente de conseguir.
2. Pedido a proveedor.
3. Backorder confirmado.
4. Recibido parcialmente.
5. Recibido completo.
6. Reservado.
7. Listo para recoger.
8. Cliente contactado.
9. Entregado.
10. Cancelado.

## Estados complementarios

- Pendiente de separar.
- Separado parcialmente.
- Incidencia.
- Vencido.
- Cerrado.

## Regla

Cada transición debe guardar usuario, fecha, hora y nota.
