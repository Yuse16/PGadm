# Pendiente de conseguir

## Uso

Cuando el producto fue vendido o comprometido, pero todavía no está disponible físicamente.

## Datos

- Producto.
- Cantidad.
- Fuente esperada.
- CEDIS.
- Proveedor.
- Fecha requerida.
- Cliente.
- Valor.
- Próximo seguimiento.

## Acciones

- Crear balanceo.
- Crear pedido.
- Registrar backorder.
- Contactar cliente.
- Cancelar con motivo.
