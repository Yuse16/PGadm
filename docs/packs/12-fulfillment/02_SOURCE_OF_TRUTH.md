# Fuente oficial

## Intelisis

Intelisis mantiene:

- Venta.
- Folio.
- Cliente.
- Productos.
- Almacén.
- Embarque oficial.
- Entrega completa registrada.

## PWA

La PWA complementa con:

- Separación física.
- Ubicación.
- Entrega parcial.
- Contacto.
- Evidencia.
- Antigüedad.
- Incidencias.
- Historial.

## Regla

La PWA no debe marcar una operación como embarcada oficialmente en Intelisis.
