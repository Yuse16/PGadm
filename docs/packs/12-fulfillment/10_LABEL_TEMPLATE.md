# Etiqueta de mercancía separada

## Encabezado obligatorio

`PRODUCTO SEPARADO — NO VENDER`

## Contenido

- Folio.
- Cliente.
- Teléfono.
- Fecha de separación.
- Fecha estimada de entrega o recolección.
- Número de cajas.
- Número de tarimas.
- Lista de productos.
- Estado de contacto.
- Responsable.
- Sucursal.

## Formato

- Texto grande.
- Alto contraste.
- Código QR futuro.
- Copias imprimibles.
