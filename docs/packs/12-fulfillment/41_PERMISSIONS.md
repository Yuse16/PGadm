# Permisos

## Vendedora

- Crear caso ligado a su venta.
- Ver sus clientes.
- Registrar contacto.
- Ver estados.
- Recibir notificaciones.

## Almacén

- Separar.
- Etiquetar.
- Ubicar.
- Registrar recepción.
- Registrar entrega.
- Reportar incidencia.

## Gerente

- Ver todos.
- Corregir.
- Cancelar.
- Autorizar liberación.
- Revisar antigüedad.
- Auditar.

## Comercial

- Ver indicadores agregados cuando tenga permiso.
