# IA para recolecciones y entregas

## Puede

- Resumir un folio.
- Preparar etiqueta.
- Preparar mensaje.
- Detectar atraso.
- Sugerir siguiente acción.
- Identificar casos críticos.
- Relacionar pedido y cliente.
- Preparar lista diaria.

## No puede

- Liberar mercancía.
- Cancelar.
- Confirmar entrega.
- Contactar automáticamente.
- Modificar Intelisis.
