# Notificaciones

## Eventos

- Producto recibido.
- Recepción parcial.
- Caso listo.
- Cliente pendiente de contacto.
- Recolección de hoy.
- Caso con 15 días.
- Caso con más de 20 días.
- Incidencia.
- Entrega parcial.
- Entrega completa.
- Cancelación.

## Regla

La notificación debe abrir el folio exacto.
