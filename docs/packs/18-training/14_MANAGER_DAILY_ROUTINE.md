# Rutina diaria del gerente

## Apertura

- Venta y presupuesto.
- Seguimientos.
- Stock crítico.
- Comercialización.
- Balanceos.
- Entregas.

## Durante el día

- Aprobar.
- Corregir.
- Resolver bloqueos.
- Revisar oportunidades.
- Apoyar vendedores.

## Cierre

- Venta total.
- Tickets.
- Pendientes.
- Incidencias.
- Siguiente día.
