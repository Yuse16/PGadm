# Criterios de aceptación

El sistema de capacitación se considera listo cuando:

1. Existe ruta por rol.
2. Existe onboarding.
3. Existen manuales operativos.
4. Existen ejercicios.
5. Existe ambiente de práctica.
6. Existe evaluación.
7. Se registra capacitación.
8. Existe centro de ayuda.
9. Existe solución de problemas.
10. Los cambios incluyen material.
11. Se mide adopción.
12. Existe soporte piloto.
13. Los materiales tienen versión.
14. La capacitación usa lenguaje claro.
15. Las acciones críticas se evalúan.
