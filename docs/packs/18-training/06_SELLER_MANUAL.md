# Manual de vendedora

## Tareas principales

- Buscar producto.
- Ver stock.
- Ver ubicación.
- Calcular m² y cajas.
- Comparar alternativas.
- Generar cotización.
- Registrar cliente.
- Crear oportunidad.
- Programar seguimiento.
- Capturar venta y tickets.

## Regla esencial

Antes de prometer una entrega, revisar:

- Fecha del inventario.
- Stock de tienda.
- Stock de CEDIS.
- Advertencias.
