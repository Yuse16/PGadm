# Estrategia de evaluación

## Métodos

- Ejercicio práctico.
- Lista de verificación.
- Preguntas breves.
- Observación.
- Uso real supervisado.

## Resultado

- Aprobado.
- Requiere práctica.
- Requiere acompañamiento.
- No autorizado todavía.

## Regla

Las acciones críticas requieren evaluación práctica.
