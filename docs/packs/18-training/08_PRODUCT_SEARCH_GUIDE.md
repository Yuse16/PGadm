# Guía de búsqueda de producto

## Formas

- Código exacto.
- Código parcial.
- Nombre.
- Marca.
- Formato.
- Color.
- Categoría.

## Buenas prácticas

- Priorizar código exacto.
- Confirmar fotografía y descripción.
- Revisar línea.
- Revisar última actualización.
- No confundir alternativas con producto original.
