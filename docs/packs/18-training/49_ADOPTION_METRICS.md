# Métricas de adopción

## Uso

- Usuarios activos.
- Frecuencia.
- Módulos.
- Búsquedas.
- Cotizaciones.
- Seguimientos.
- Importaciones.
- Uso de layout.
- Recomendaciones revisadas.

## Calidad

- Errores.
- Datos incompletos.
- Tareas abandonadas.
- Solicitudes duplicadas.
- Tiempo por flujo.

## Regla

No medir adopción únicamente por inicios de sesión.
