# Guía de layout

## Consulta

- Abrir layout.
- Buscar mueble.
- Tocar ubicación.
- Revisar producto.
- Revisar stock.
- Ver alertas.

## Edición

- Entrar a modo edición.
- Mover.
- Rotar.
- Redimensionar.
- Asignar producto.
- Guardar borrador.
- Publicar.

## Regla

Editar no significa publicar.
