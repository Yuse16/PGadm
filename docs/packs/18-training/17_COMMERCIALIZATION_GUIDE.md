# Guía de comercialización

## Flujo

1. Crear o abrir mes.
2. Cargar PDF.
3. Cargar audio.
4. Revisar transcripción.
5. Consultar IA.
6. Revisar borrador.
7. Editar checklist.
8. Aprobar.
9. Ejecutar.
10. Adjuntar evidencia.
11. Completar.

## Regla

Una nueva versión muestra cambios nuevos y conserva el historial.
