# Guía de calculadora

## Pasos

1. Capturar área.
2. Seleccionar desperdicio.
3. Revisar m² por caja.
4. Confirmar cajas.
5. Revisar sobrante.
6. Revisar stock.
7. Agregar complementos.

## Errores comunes

- No agregar desperdicio.
- Capturar centímetros como metros.
- Redondear cajas hacia abajo.
- Ignorar diferentes áreas.
