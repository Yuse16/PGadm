# Primer inicio de sesión

## Flujo

1. Abrir invitación.
2. Crear acceso.
3. Confirmar nombre.
4. Confirmar sucursal.
5. Confirmar rol.
6. Revisar navegación.
7. Activar notificaciones permitidas.
8. Completar ejercicio inicial.

## Validación

El usuario debe poder:

- Entrar.
- Identificar su sucursal.
- Encontrar búsqueda.
- Abrir ayuda.
