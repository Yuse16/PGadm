# Notificaciones push

## Eventos

- Seguimiento.
- Solicitud CEDIS.
- Mercancía recibida.
- Comercialización.
- Incidencia.
- Seguridad.
- Error de sincronización.

## Requisitos

- Consentimiento.
- Preferencias.
- Identificador de dispositivo.
- Revocación.
- Enlace profundo.

## Regla

No incluir datos sensibles completos en la notificación.
