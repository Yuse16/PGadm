# Niveles de integración

## Nivel 0 — Manual

El usuario captura o carga información.

## Nivel 1 — Importación de archivo

Excel, CSV, PDF o audio.

## Nivel 2 — Conector local

Un servicio autorizado consulta o prepara archivos.

## Nivel 3 — Lectura directa

SQL, API o cubo con acceso de solo lectura.

## Nivel 4 — Sincronización bidireccional

Solo después de aprobación técnica, operativa y de seguridad.

## Regla inicial

La PWA comienza entre Nivel 1 y Nivel 2.
