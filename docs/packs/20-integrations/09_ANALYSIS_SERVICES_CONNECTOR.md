# Conector Analysis Services

## Uso

Consultar cubos autorizados para inventario, ventas u otros indicadores.

## Posibles tecnologías

- XMLA.
- MDX.
- DAX, cuando corresponda.
- Exportación mediante herramienta corporativa.

## Requisitos

- Cubo identificado.
- Medidas confirmadas.
- Dimensiones confirmadas.
- Frecuencia.
- Usuario autorizado.
- Límites de consulta.

## Regla

No asumir que una medida representa disponible, reservado o movimiento sin definición oficial.
