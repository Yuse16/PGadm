# Registro de conectores

## Cada conector debe registrar

- Código.
- Nombre.
- Tipo.
- Proveedor.
- Versión.
- Alcance.
- Estado.
- Sucursales.
- Credenciales.
- Última ejecución.
- Último resultado.
- Responsable.

## Estados

- Configurando.
- Activo.
- Degradado.
- Suspendido.
- Error.
- Retirado.
