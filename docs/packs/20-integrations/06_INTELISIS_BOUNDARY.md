# Límite con Intelisis

## Permitido inicialmente

- Importar archivos autorizados.
- Consultar exportaciones.
- Guardar folios externos.
- Comparar información.
- Preparar acciones para captura manual.

## Prohibido inicialmente

- Escribir en la base.
- Modificar movimientos.
- Cambiar stock.
- Crear OC oficial.
- Marcar embarques.
- Extraer credenciales.
- Automatizar la interfaz sin autorización.

## Futuro

Cualquier escritura requiere:

- autorización de TI,
- ambiente de pruebas,
- permisos mínimos,
- auditoría,
- rollback.
