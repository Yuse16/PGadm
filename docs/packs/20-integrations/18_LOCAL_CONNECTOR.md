# Conector local

## Propósito

Automatizar la obtención de archivos o consultas desde una computadora autorizada dentro de la red.

## Componentes

- Servicio local.
- Configuración.
- Autenticación.
- Carpeta vigilada.
- Programación.
- Cifrado.
- Cola.
- Logs.
- Actualización.

## Restricción

No debe abrir acceso entrante público a la red interna.
