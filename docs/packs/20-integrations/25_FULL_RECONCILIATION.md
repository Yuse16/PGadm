# Reconciliación completa

## Objetivo

Detectar registros perdidos, duplicados o desalineados.

## Frecuencia

Según volumen y estabilidad.

## Resultado

- Coincidentes.
- Faltantes internos.
- Faltantes externos.
- Diferencias.
- Conflictos.
- Acciones sugeridas.

## Regla

No corregir automáticamente datos oficiales.
