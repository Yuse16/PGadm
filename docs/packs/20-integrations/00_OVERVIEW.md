# Overview

## Propósito

Permitir que la PWA utilice información externa sin quedar amarrada a un solo proveedor, archivo, protocolo o sistema.

## Integraciones principales

- Intelisis.
- SQL Server.
- Analysis Services.
- Cubos.
- Excel.
- Almacenamiento de archivos.
- OpenRouter.
- Proveedores alternativos de IA.
- Transcripción.
- Correo.
- WhatsApp.
- Notificaciones push.
- Fichas técnicas de fabricantes.

## Principio

Cada integración debe quedar detrás de un adaptador con contrato estable.
