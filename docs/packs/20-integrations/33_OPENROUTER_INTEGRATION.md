# Integración OpenRouter

## Uso inicial deseado

- Chat.
- Resumen.
- Análisis de documentos.
- Generación de borradores.

## Configuración

- API key.
- Modelo principal.

- Límites.
- Timeout.
- Reintentos.
- Costo.
- Módulos permitidos.

La disponibilidad de modelos gratuitos puede cambiar.

La arquitectura debe soportar sustitución.
