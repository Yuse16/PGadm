# Conector Excel

## Primera versión

Carga manual de archivo actualizado desde la herramienta existente.

## Flujo

1. Usuario actualiza Excel.
2. Usuario guarda copia.
3. Usuario carga archivo.
4. PWA valida.
5. PWA mapea.
6. PWA crea snapshot.
7. PWA detecta cambios.
8. PWA entrega reporte.

## Regla

No modificar el archivo original.
