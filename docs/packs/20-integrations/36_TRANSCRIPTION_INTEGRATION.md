# Integración de transcripción

## Entradas

- Audio.
- Video futuro.
- Formatos permitidos.
- Idioma.
- Duración.

## Salidas

- Texto.
- Segmentos.
- Marcas de tiempo.
- Confianza.
- Identificación de hablantes cuando sea posible.

## Regla

La transcripción puede requerir un servicio diferente al modelo de chat.
