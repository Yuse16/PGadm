# Pipeline de transcripción

1. Validar archivo.
2. Almacenar original.
3. Convertir formato cuando sea necesario.
4. Dividir archivo.
5. Transcribir.
6. Unir segmentos.
7. Detectar fallas.
8. Guardar.
9. Permitir corrección.
10. Analizar.

## Regla

Nunca eliminar el audio original durante el procesamiento.
