# Enrutamiento de modelos

## Tareas simples

- Clasificación.
- Resumen corto.
- Extracción.

## Tareas complejas

- Análisis de múltiples fuentes.
- Recomendaciones.
- Comparación.
- Conflictos.

## Criterios

- Calidad.
- Costo.
- Latencia.
- Privacidad.
- Contexto.
- Disponibilidad.

## Regla

El usuario no debe depender de conocer el nombre del modelo.
