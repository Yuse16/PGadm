# Cubo actual de inventario

## Conocimiento disponible

El archivo actual permite consultar existencia total por producto y almacén.

## Limitaciones conocidas

No se ha confirmado disponibilidad de:

- Reservado.
- Backorder.
- Separado.
- Pedido.
- Tránsito.
- Causa de movimiento.
- Venta.
- Recepción.

## Regla

La PWA debe presentar el dato como existencia reportada, no como disponibilidad garantizada.
