# Criterios de aceptación

El sistema de integraciones se considera listo cuando:

1. Existen adaptadores.
2. Intelisis está limitado a lectura o archivo autorizado.
3. Excel crea snapshots auditables.
4. Se detectan duplicados.
5. Se conserva linaje.
6. Se programan sincronizaciones.
7. Existen reintentos controlados.
8. Existen circuit breakers.
9. Las credenciales están protegidas.
10. Las fallas muestran modo degradado.
11. Existe alternativa manual.
12. Se monitorea la salud.
13. Se registran errores.
14. Los contratos están versionados.
15. La activación es gradual.
