# Resolución de productos

## Prioridad

1. Código exacto.
2. Referencia externa confirmada.
3. Código alterno aprobado.
4. Coincidencia manual.

## No permitido automáticamente

- Coincidencia por descripción aproximada como definitiva.
- Fusión de códigos distintos.
- Sustitución de producto.

## Resultado

- Encontrado.
- Nuevo.
- Ambiguo.
- No encontrado.
