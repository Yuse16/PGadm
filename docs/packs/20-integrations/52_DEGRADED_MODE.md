# Modo degradado

## Ejemplos

- IA no disponible.
- Inventario desactualizado.
- Transcripción pendiente.
- WhatsApp no disponible.
- Cubo no responde.

## La PWA debe

- Mantener funciones locales.
- Mostrar advertencia.
- Indicar última actualización.
- Guardar borradores.
- Ofrecer reintento.
- No inventar datos.
