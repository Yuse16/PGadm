# Respaldo de IA

## Casos

- Modelo no disponible.
- Límite alcanzado.
- Tiempo de espera.
- Respuesta inválida.
- Error del proveedor.

## Estrategia

1. Reintento controlado.
2. Modelo alternativo.
3. Proveedor alternativo.
4. Flujo manual.
5. Notificación.

## Regla

No repetir indefinidamente una petición costosa.
