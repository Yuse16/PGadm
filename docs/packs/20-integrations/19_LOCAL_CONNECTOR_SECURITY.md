# Seguridad del conector local

## Requisitos

- Identificador único.
- Clave rotatoria.
- Comunicación saliente.
- TLS.
- Lista de tareas permitidas.
- Usuario de sistema limitado.
- Actualización firmada.
- Registro local.
- Revocación remota.

## Prohibido

- Ejecutar comandos arbitrarios.
- Usar credenciales personales.
- Exponer carpetas completas.
