# Catálogo de errores

## Categorías

- Autenticación.
- Autorización.
- Red.
- Timeout.
- Formato.
- Validación.
- Mapeo.
- Duplicado.
- Límite.
- Proveedor.
- Contrato.
- Interno.

## Cada error debe definir

- Código.
- Mensaje técnico.
- Mensaje al usuario.
- Reintentable.
- Acción.
- Severidad.
