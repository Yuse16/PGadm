# Estrategia de solo lectura

## Opciones

- Vista SQL autorizada.
- Stored procedure de consulta.
- API corporativa.
- Exportación programada.
- Cubo.
- Conector local.

## Requisitos

- Usuario técnico de solo lectura.
- Lista blanca.
- Consultas limitadas.
- Índices revisados.
- Sin exposición pública.
- Registro de accesos.

## Regla

La aplicación no debe conectarse directamente desde el navegador.
