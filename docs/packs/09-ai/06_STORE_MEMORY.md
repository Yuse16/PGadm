# Memoria de sucursal

## Propósito

Conservar la experiencia operativa de cada tienda.

## Contenido

- Productos más vendidos.
- Productos más solicitados.
- Ventas perdidas.
- Demanda no atendida.
- Historial de layout.
- Resultados de movimientos.
- Comercializaciones.
- Balanceos.
- Solicitudes.
- Proveedores.
- Incidencias.
- Decisiones del gerente.

## Regla

La memoria de Nogalera no se convierte automáticamente en regla para otra sucursal.
