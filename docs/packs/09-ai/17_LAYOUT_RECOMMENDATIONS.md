# Recomendaciones de layout

## Puede sugerir

- Cambiar producto.
- Mover muestra.
- Priorizar entrada.
- Completar mueble.
- Retirar muestra sin stock.
- Reemplazar producto dañado.
- Destacar promoción.
- Reorganizar M1.

## Debe considerar

- Tipo de mueble.
- Capacidad.
- Proveedor.
- Formato.
- Stock.
- Comercialización.
- Ventas.
- Historial.

## Regla

No mover ni actualizar el layout sin aprobación.
