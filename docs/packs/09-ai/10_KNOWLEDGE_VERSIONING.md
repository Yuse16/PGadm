# Versionado de conocimiento

## Regla

Cada regla aprobada debe tener versión.

## Ejemplo

- `BALANCEO_PISOS_v1`
- `BALANCEO_PISOS_v2`

## Historial

Debe conservar:

- Texto anterior.
- Texto nuevo.
- Motivo.
- Fuente.
- Aprobador.
- Fecha.
- Sucursales afectadas.

## Reversión

Una versión anterior puede restaurarse, dejando auditoría.
