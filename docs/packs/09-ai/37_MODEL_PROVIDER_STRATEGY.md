# Estrategia de proveedores de IA

## Objetivo

Permitir cambiar de modelo sin rehacer la PWA.

## Adaptadores sugeridos

- `ChatModelProvider`
- `EmbeddingProvider`
- `TranscriptionProvider`
- `DocumentAnalysisProvider`

## OpenRouter

Puede utilizarse inicialmente para modelos de texto y análisis de documentos, sujeto a disponibilidad, límites y costo.

## Regla

No depender de un único modelo.
