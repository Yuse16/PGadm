# Comportamiento sin conexión

## Funciones posibles offline

- Consultar datos sincronizados.
- Ver layout.
- Ver fichas guardadas.
- Crear borradores.
- Registrar notas.
- Preparar cotización.
- Guardar cambios pendientes.

## IA offline

No se garantiza en la primera versión.

## Sincronización

Al recuperar conexión:

- Enviar borradores.
- Resolver conflictos.
- Actualizar inventario.
- Registrar fecha real.
