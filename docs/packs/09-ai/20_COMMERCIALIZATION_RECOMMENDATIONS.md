# Recomendaciones de comercialización

## Puede

- Leer materiales.
- Generar checklist.
- Detectar productos.
- Relacionar layout.
- Señalar etiquetas.
- Detectar cambios.
- Marcar dudas.
- Sugerir prioridades.

## No puede

- Aprobar checklist.
- Sustituir productos exactos.
- Inventar instrucciones.
- Cambiar campañas.
