# Ciclo de retroalimentación

## Después de una recomendación

Registrar:

- Fue aceptada.
- Fue rechazada.
- Fue modificada.
- Se ejecutó.
- Resultado.
- Comentario.

## Objetivo

Medir qué recomendaciones ayudan realmente.

## Regla

Un rechazo no significa automáticamente que la recomendación era incorrecta.
Debe guardarse el motivo.
