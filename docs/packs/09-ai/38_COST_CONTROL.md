# Control de costo

## Estrategias

- Usar modelos económicos para tareas simples.
- Usar modelos potentes solo cuando sea necesario.
- Resumir documentos una vez.
- Guardar embeddings.
- Reutilizar resultados.
- Limitar contexto.
- Procesar por lotes.
- Mostrar consumo por módulo.

## Alertas

- Límite mensual.
- Consumo alto.
- Archivo demasiado grande.
- Modelo no disponible.
