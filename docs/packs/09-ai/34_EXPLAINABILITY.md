# Explicabilidad

## Toda recomendación importante debe incluir

- Acción.
- Motivo.
- Datos usados.
- Fuente.
- Fecha de datos.
- Confianza.
- Alternativa.
- Riesgo.

## Ejemplo

`Sugiero mover este producto a la entrada porque está en comercialización, tiene stock suficiente en tienda y recibió más consultas que otros productos similares durante el mes. Confianza media: todavía no existe cubo de ventas para confirmar conversión.`
