# Conocimiento oficial

## Definición

Información aprobada que la IA puede utilizar como regla.

## Ejemplos

- Intelisis es la fuente oficial de stock.
- Remate no se resurte.
- Comercialización es mensual.
- M1 tiene rieles y posiciones.
- Una promoción se aplica al código exacto.
- El gerente aprueba checklist.

## Origen

- Corporativo.
- Intelisis.
- Gerente autorizado.
- Comercial.
- TI.
- Documento aprobado.

## Regla

El conocimiento oficial debe tener:

- Fuente.
- Autor.
- Fecha.
- Versión.
- Estado.
