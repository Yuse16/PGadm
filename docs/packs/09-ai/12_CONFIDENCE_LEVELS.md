# Niveles de confianza

## Alta

- Fuente oficial.
- Dato reciente.
- Regla confirmada.
- Sin conflicto.

## Media

- Cubo actualizado.
- Patrón repetido.
- Falta una variable secundaria.

## Baja

- Observación aislada.
- Datos antiguos.
- Fuente incompleta.
- Conflicto entre fuentes.

## Presentación

La IA debe mostrar el nivel cuando la decisión tenga impacto operativo o comercial.
