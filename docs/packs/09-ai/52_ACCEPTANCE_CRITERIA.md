# Criterios de aceptación

El sistema de IA se considera funcional cuando:

1. Consulta fuentes antes de responder datos variables.
2. Respeta jerarquía de fuentes.
3. Separa conocimiento oficial y observado.
4. Aprende por sucursal.
5. Explica recomendaciones.
6. Muestra incertidumbre.
7. No inventa stock, precio o reglas.
8. Prepara acciones sin ejecutarlas automáticamente.
9. Requiere aprobación.
10. Conserva historial.
11. Registra resultado de recomendaciones.
12. Maneja permisos.
13. Puede cambiar de proveedor de modelo.
14. Controla costos.
15. Tiene agentes especializados.
