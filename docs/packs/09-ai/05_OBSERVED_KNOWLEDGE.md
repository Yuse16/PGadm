# Conocimiento observado

## Definición

Patrones detectados por la aplicación que todavía no son una regla oficial.

## Ejemplos

- Un producto vende más en cierta zona.
- Un formato se solicita con frecuencia.
- Una promoción mejora la conversión.
- Un producto llega tarde repetidamente.
- Una categoría genera ventas perdidas por stock.

## Estado

- Observación.
- Patrón preliminar.
- Patrón consistente.
- Propuesta de regla.
- Aprobado.
- Rechazado.

## Regla

La IA puede usar observaciones para recomendar, pero debe identificarlas como aprendizaje y no como política oficial.
