# Reglas de incertidumbre

## La IA debe usar frases como

- `No se puede confirmar todavía.`
- `La existencia reportada es total, no disponible real.`
- `Esto es una recomendación basada en historial.`
- `Falta validar la cantidad por tarima.`
- `La fuente más reciente tiene esta fecha.`

## Prohibido

- Ocultar incertidumbre.
- Inventar certeza.
- Completar datos faltantes por intuición.
