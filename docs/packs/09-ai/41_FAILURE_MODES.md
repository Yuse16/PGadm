# Manejo de fallas

## Casos

- Modelo no disponible.
- Transcripción fallida.
- PDF ilegible.
- Inventario desactualizado.
- Fuente faltante.
- Permiso insuficiente.
- Conflicto de datos.
- Tiempo de espera.

## Comportamiento

- No perder borrador.
- Informar claramente.
- Permitir reintento.
- Ofrecer flujo manual.
- Registrar error.
