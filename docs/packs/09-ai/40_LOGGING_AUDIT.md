# Logs y auditoría

## Registrar

- Consulta.
- Herramientas usadas.
- Fuentes.
- Respuesta.
- Acción propuesta.
- Usuario.
- Sucursal.
- Fecha y hora.
- Aprobación.
- Resultado.

## Privacidad

Los logs no deben exponer información innecesaria.

## Uso

- Auditoría.
- Mejora.
- Corrección.
- Seguridad.
- Medición.
