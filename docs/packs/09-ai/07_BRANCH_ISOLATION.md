# Separación por sucursal

## Regla principal

Cada sucursal aprende por separado.

## Datos locales

- Demanda.
- Conversión.
- Productos.
- Layout.
- Inventario.
- Clientes.
- Proveedores frecuentes.
- Tiempos de CEDIS.
- Motivos de pérdida.
- Resultados de exhibición.

## Consulta cruzada

La IA puede decir:

`En otra sucursal funcionó esta estrategia.`

Pero debe presentarlo como referencia, no como regla aplicable automáticamente.
