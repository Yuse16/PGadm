# Privacidad y seguridad

## Datos sensibles

- Clientes.
- Ventas.
- Precios.
- Costos.
- Proveedores.
- Juntas.
- Usuarios.
- Estrategias.
- Inventario.

## Reglas

- Acceso por rol.
- Contexto limitado por sucursal.
- No exponer información interna.
- Registrar accesos sensibles.
- Proteger archivos.
- Minimizar datos enviados a proveedores de IA.
