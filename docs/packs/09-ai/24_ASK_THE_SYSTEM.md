# Pregúntale al sistema

## Ejemplos

- ¿Dónde está este producto?
- ¿Cuánto stock tenemos?
- ¿Qué producto se parece más?
- ¿Qué falta en la comercialización?
- ¿Qué balanceos debo preparar?
- ¿Qué clientes debo contactar?
- ¿Qué cambió desde ayer?
- ¿Qué tareas están atrasadas?
- ¿Qué puedo mejorar hoy?

## Contexto

La respuesta debe respetar permisos y sucursal.
