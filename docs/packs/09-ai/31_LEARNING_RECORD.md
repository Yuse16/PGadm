# Registro de aprendizaje

## Campos

- Sucursal.
- Módulo.
- Observación.
- Evidencia.
- Número de casos.
- Periodo.
- Confianza.
- Impacto.
- Propuesta.
- Estado.
- Revisado por.
- Fecha.

## Ejemplo

`Los porcelanatos grises en M1-02 recibieron más consultas durante cuatro semanas.`

Esto es una observación, no una regla oficial.
