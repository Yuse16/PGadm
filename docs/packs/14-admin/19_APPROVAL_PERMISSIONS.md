# Permisos de aprobación

## Acciones críticas

- Aprobar comercialización.
- Publicar layout.
- Enviar balanceo.
- Aceptar solicitud.
- Autorizar liberación de mercancía.
- Aprobar nueva regla de conocimiento.
- Reasignar oportunidades.
- Corregir ventas.
- Exportar información sensible.

## Regla

El permiso de editar no implica permiso de aprobar.
