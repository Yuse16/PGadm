# Alertas de seguridad

## Eventos

- Muchos intentos fallidos.
- Acceso desde dispositivo nuevo.
- Cambio de permisos.
- Exportación masiva.
- Uso atípico.
- Integración fallida.
- Clave próxima a vencer.
- Acceso fuera de alcance.

## Respuesta

- Notificar.
- Bloquear cuando corresponda.
- Revocar sesión.
- Solicitar revisión.
