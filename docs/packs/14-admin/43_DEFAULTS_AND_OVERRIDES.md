# Valores generales y excepciones

## Jerarquía

1. Configuración de organización.
2. Configuración de sucursal.
3. Configuración de rol.
4. Preferencia del usuario.

## Regla

Cada campo debe definir si admite excepción local.

## Ejemplo

- Alerta general de apartados: 20 días.
- Una sucursal puede usar otro valor solo con permiso.
