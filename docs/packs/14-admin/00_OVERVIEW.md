# Overview

## Propósito

Permitir que la PWA crezca sin depender de cambios de código para cada usuario, sucursal, permiso, catálogo o regla operativa.

## El panel administrativo debe controlar

- Usuarios.
- Roles.
- Permisos.
- Sucursales.
- Almacenes.
- Relaciones tienda–CEDIS.
- Catálogos.
- Configuraciones.
- Integraciones.
- Proveedores de IA.
- Límites.
- Auditoría.
- Seguridad.
- Funciones activas.

## Principio

Una persona solo debe ver y ejecutar lo necesario para su función.
