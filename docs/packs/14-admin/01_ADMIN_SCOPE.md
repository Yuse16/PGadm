# Alcance administrativo

## Incluido

- Alta, edición y desactivación de usuarios.
- Roles globales y por sucursal.
- Permisos granulares.
- Catálogos configurables.
- Configuración por organización y sucursal.
- Bitácora de cambios.
- Sesiones.
- Recuperación de acceso.
- Integraciones.
- Feature flags.
- Límites de IA.
- Exportación administrativa.

## Fuera de alcance inicial

- Nómina.
- Recursos humanos.
- Control biométrico.
- Directorio corporativo externo.
- Inicio de sesión único empresarial.
