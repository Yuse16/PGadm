# Bitácora de auditoría

- Inicio de sesión.
- Cambio de permiso.
- Alta o baja.
- Edición de configuración.
- Publicación.
- Aprobación.
- Exportación.
- Integración.
- Cambio de catálogo.

- Valor anterior.
- Valor nuevo.
