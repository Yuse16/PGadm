# Configuración por sucursal

## Opciones

- CEDIS principal.
- Días de balanceo.
- Horario.
- Umbrales de stock.
- Vigencia de cotización.
- Días de alerta de apartados.
- Layout activo.
- Módulos visibles.
- Notificaciones.
- Idioma.
- Zona horaria.

## Regla

Una configuración local no debe modificar otras tiendas.
