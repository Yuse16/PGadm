# Roles personalizados

## Objetivo

Permitir combinaciones especiales sin modificar código.

## Ejemplos

- Supervisora de varias tiendas.
- Auditor de comercialización.
- Solo lectura.
- Apoyo temporal de inventario.
- Responsable de proveedores.

## Campos

- Nombre.
- Descripción.
- Permisos.
- Alcance.
- Estado.
- Creado por.
- Fecha.
