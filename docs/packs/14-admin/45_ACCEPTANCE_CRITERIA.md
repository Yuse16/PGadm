# Criterios de aceptación

El panel administrativo se considera funcional cuando:

1. Crea y desactiva usuarios.
2. Asigna roles por sucursal.
3. Maneja permisos granulares.
4. Permite acceso temporal.
5. Administra sucursales y almacenes.
6. Administra catálogos.
7. Configura integraciones.
8. Configura proveedores y límites de IA.
9. Maneja feature flags.
10. Conserva auditoría.
11. Permite revocar sesiones.
12. Muestra alertas de seguridad.
13. Respeta jerarquía de configuraciones.
14. No elimina historial al desactivar.
15. Aplica permisos también en servidor.
