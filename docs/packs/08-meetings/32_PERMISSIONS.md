# Permisos

## Usuario participante

- Ver junta autorizada.
- Agregar nota.
- Consultar acuerdos.
- Cumplir tarea.

## Gerente

- Crear junta.
- Cargar materiales.
- Editar borradores.
- Aprobar.
- Cerrar.
- Crear versiones.

## Comercial

- Ver varias sucursales.
- Aprobar según permiso.
- Crear complementos.
- Consultar historial.

## Administrador

- Configurar permisos.
- Gestionar servicios.
- Auditar.
