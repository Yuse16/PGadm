# Transcripción

## Flujo

1. Usuario carga audio.
2. Sistema valida formato.
3. Se envía al servicio de transcripción.
4. Se guarda transcripción.
5. Se relaciona con el audio original.
6. Se analiza junto con otros materiales.

## Resultado

- Texto completo.
- Marcas de tiempo.
- Separación por segmentos.
- Idioma.
- Confianza.
- Fragmentos no entendidos.

## Regla

La transcripción es una interpretación técnica y puede contener errores.

El usuario debe poder corregirla.
