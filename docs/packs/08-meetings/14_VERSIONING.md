# Versionado

## Versiones

- v1: primera interpretación.
- v2: complemento o corrección.
- v3: cambio posterior.

## Vista

La nueva versión debe mostrar principalmente cambios nuevos.

## Historial

Cada versión conserva:

- Materiales.
- Transcripción.
- Chat.
- Acuerdos.
- Tareas.
- Aprobación.
- Cambios.
