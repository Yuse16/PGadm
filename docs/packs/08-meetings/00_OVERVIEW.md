# Overview

## Propósito

Convertir juntas, audios, PDF, notas y conversaciones en acuerdos claros, tareas ejecutables e historial consultable.

## Problema

La información importante puede quedar repartida entre:

- Audio.
- PDF.
- Correo.
- WhatsApp.
- Notas.
- Memoria de los asistentes.

## Resultado esperado

La PWA debe:

- Crear una junta.
- Agregar varios archivos.
- Transcribir audio.
- Analizar todo el contexto.
- Permitir preguntas a la IA.
- Generar acuerdos y tareas.
- Requerir aprobación humana.
- Mantener versiones.
- Conservar evidencia e historial.
