# Contradicciones

## Ejemplos

- PDF indica una etiqueta.
- Audio menciona otra.
- Una versión cambia una instrucción.
- Dos participantes proponen fechas distintas.

## Comportamiento

La PWA debe:

- Detectar posible conflicto.
- Mostrar fuentes.
- Evitar decidir sola.
- Pedir confirmación.
- Guardar resolución aprobada.
