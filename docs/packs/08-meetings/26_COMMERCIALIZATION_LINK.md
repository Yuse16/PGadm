# Relación con comercialización

## Flujo

Una junta de comercialización puede:

- Crear período mensual.
- Agregar PDF.
- Agregar audio.
- Generar checklist.
- Relacionar etiquetas.
- Relacionar productos.
- Relacionar layout.
- Crear versión.

## Regla

Los acuerdos aprobados alimentan el módulo de Comercialización.
