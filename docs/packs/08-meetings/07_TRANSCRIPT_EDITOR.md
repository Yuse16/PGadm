# Editor de transcripción

## Funciones

- Corregir palabras.
- Agregar puntuación.
- Renombrar hablantes.
- Marcar fragmentos importantes.
- Agregar nota.
- Marcar duda.
- Escuchar desde una marca de tiempo.

## Auditoría

Cada edición debe guardar:

- Texto anterior.
- Texto nuevo.
- Usuario.
- Fecha y hora.
