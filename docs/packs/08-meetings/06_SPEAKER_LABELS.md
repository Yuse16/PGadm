# Identificación de hablantes

## Objetivo

Separar participaciones cuando la tecnología lo permita.

## Etiquetas iniciales

- Persona 1.
- Persona 2.
- Persona 3.

## Corrección

El usuario puede cambiar:

- Persona 1 → Gerente.
- Persona 2 → Comercial.
- Persona 3 → CEDIS.

## Restricción

La PWA no debe inventar identidades.
