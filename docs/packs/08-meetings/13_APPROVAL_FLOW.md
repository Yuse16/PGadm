# Flujo de aprobación

## Antes de aprobar

El usuario puede:

- Editar acuerdos.
- Agregar acuerdos.
- Eliminar borradores.
- Dividir acuerdos.
- Unir acuerdos.
- Preguntar a la IA.
- Revisar audio.
- Revisar PDF.
- Corregir transcripción.

## Después de aprobar

- Los acuerdos quedan oficiales.
- Se crean tareas aprobadas.
- Se guarda versión.
- Se registra usuario, fecha y hora.
- El material original permanece disponible.
