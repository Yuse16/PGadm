# Generación de tareas

## Origen

Las tareas pueden generarse desde:

- Acuerdo.
- Instrucción.
- PDF.
- Audio.
- Chat.
- Nota manual.

## Campos

- Título.
- Descripción.
- Módulo relacionado.
- Sucursal.
- Responsable.
- Fecha.
- Prioridad.
- Evidencia.
- Estado.

## Regla

La IA genera borradores.

El usuario autorizado confirma antes de volverlas oficiales.
