# Privacidad y seguridad

## Riesgos

Las juntas pueden contener:

- Datos personales.
- Precios.
- Estrategias.
- Información de proveedores.
- Información interna.
- Decisiones sensibles.

## Reglas

- Acceso por roles.
- Archivos privados.
- Registro de accesos.
- Enlaces con caducidad.
- No compartir fuera de la empresa.
- No usar transcripciones para fines no autorizados.
