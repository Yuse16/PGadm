# Fechas compromiso

## Tipos

- Fecha exacta.
- Rango.
- Antes de visita.
- Esta semana.
- Próximo balanceo.
- Fin de mes.
- Sin fecha.

## Conversión

La IA puede proponer una fecha interpretada, pero debe mostrar el texto original.

## Regla

Cuando la fecha sea ambigua, marcarla para confirmación.
