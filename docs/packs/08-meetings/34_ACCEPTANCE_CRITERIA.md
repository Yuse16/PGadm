# Criterios de aceptación

El módulo se considera funcional cuando:

1. Crea juntas.
2. Permite varios archivos.
3. Transcribe audio.
4. Conserva audio original.
5. Permite corregir transcripción.
6. Analiza PDF, audio y notas.
7. Permite chat contextual.
8. Genera acuerdos en borrador.
9. Genera tareas en borrador.
10. Requiere aprobación.
11. Maneja versiones.
12. Muestra cambios nuevos.
13. Detecta contradicciones.
14. Marca dudas.
15. Mantiene historial.
16. Relaciona otros módulos.
17. Respeta permisos.
18. No inventa acuerdos.
