# Materiales fuente

## Tipos permitidos

- Audio.
- PDF.
- Documento.
- Imagen.
- Texto.
- Nota.
- Transcripción.
- Correo copiado.
- Enlace.

## Metadatos

Cada elemento debe guardar:

- Nombre.
- Tipo.
- Fecha.
- Hora.
- Usuario.
- Junta.
- Versión.
- Estado de procesamiento.
- Tamaño.
- Fuente.
