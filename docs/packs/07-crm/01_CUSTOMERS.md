# Clientes

## Campos mínimos

- Nombre.
- Teléfono.
- WhatsApp.
- Sucursal.
- Vendedora responsable.
- Fecha de alta.

## Campos opcionales

- Correo.
- Empresa.
- Dirección.
- Tipo de cliente.
- Notas.
- Preferencias.
- Consentimiento de contacto.

## Regla

Un cliente puede tener varios proyectos y varias oportunidades.
