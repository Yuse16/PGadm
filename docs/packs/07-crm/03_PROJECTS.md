# Proyectos del cliente

## Campos

- Tipo de espacio.
- Nombre del proyecto.
- Medidas y m².
- Presupuesto.
- Fecha probable de compra.
- Fecha requerida.
- Estilo, colores y formatos.
- Uso interior o exterior.
- Productos de interés.
- Observaciones.

## Ejemplos

Baño, cocina, sala, fachada, patio, local comercial o remodelación completa.
