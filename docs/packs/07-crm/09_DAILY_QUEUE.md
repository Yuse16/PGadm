# Cola diaria

Debe mostrar:

- Seguimientos de hoy.
- Seguimientos vencidos.
- Clientes sin respuesta.
- Cotizaciones por vencer.
- Productos nuevamente disponibles.
- Solicitudes CEDIS actualizadas.
- Oportunidades de alto valor.
- Clientes con compra próxima.

## Prioridad

1. Compra inmediata.
2. Alto valor.
3. Stock recién disponible.
4. Seguimiento vencido.
5. Cotización por vencer.
