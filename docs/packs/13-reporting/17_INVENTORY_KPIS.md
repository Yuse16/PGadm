# KPIs de inventario

## Indicadores

- Productos con stock.
- Productos sin stock.
- Stock bajo.
- Productos exhibidos sin existencia.
- Productos tienda cero / CEDIS con stock.
- Cambios detectados.
- Días desde actualización.
- Productos ausentes del archivo.
- Demanda recurrente.

## Precaución

No calcular rotación real hasta disponer de movimientos o ventas confiables.
