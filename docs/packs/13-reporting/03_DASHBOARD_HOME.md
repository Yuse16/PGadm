# Dashboard principal

## Objetivo

Dar una vista ejecutiva del día y del mes.

## Secciones

- Venta del día.
- Venta del mes.
- Presupuesto.
- Porcentaje alcanzado.
- Venta diaria requerida.
- Tickets.
- Ticket promedio.
- Oportunidades abiertas.
- Seguimientos pendientes.
- Comercialización.
- Stock crítico.
- Balanceos.
- Recolecciones.
- Alertas.
- Recomendación de IA.

## Acción rápida

Cada tarjeta debe abrir el módulo relacionado.
