# Insights de IA

## Puede responder

- ¿Por qué vamos abajo?
- ¿Qué puede aumentar la venta hoy?
- ¿Qué productos están generando pérdidas?
- ¿Qué clientes debo contactar?
- ¿Qué balanceos tendrían mayor impacto?
- ¿Qué cambió esta semana?
- ¿Qué zona del layout requiere atención?
- ¿Qué proveedor está fallando?

## Respuesta

Debe incluir:

- Hallazgo.
- Evidencia.
- Periodo.
- Fuente.
- Confianza.
- Acción sugerida.
