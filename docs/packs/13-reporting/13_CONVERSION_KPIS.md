# KPIs de conversión

## Conversión de oportunidad

`oportunidades_ganadas / oportunidades_cerradas * 100`

## Conversión de cotización

`cotizaciones_vendidas / cotizaciones_enviadas * 100`

## Conversión de seguimiento

`ventas_recuperadas / oportunidades_contactadas * 100`

## Regla

No calcular conversión con oportunidades todavía abiertas como perdidas.
