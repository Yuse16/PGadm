# Criterios de aceptación

El pack se considera implementado cuando:

1. Existe dashboard por rol.
2. Cada cifra muestra fuente y periodo.
3. Se distingue manual de oficial.
4. El dashboard abre módulos relacionados.
5. Existen alertas priorizadas.
6. Se calculan venta, presupuesto, tickets y conversión.
7. Existen indicadores de inventario, CRM, CEDIS y operación.
8. Se permiten filtros.
9. Se permiten exportaciones autorizadas.
10. La IA genera insights explicables.
11. Los comparativos respetan contexto.
12. Existe diccionario de métricas.
13. Se conserva auditoría.
