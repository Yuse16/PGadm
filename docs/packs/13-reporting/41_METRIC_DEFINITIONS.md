# Diccionario de métricas

## Cada métrica debe definir

- Nombre.
- Descripción.
- Fórmula.
- Fuente.
- Periodicidad.
- Unidad.
- Responsable.
- Restricciones.
- Versión.

## Ejemplo

### Venta acumulada mensual

Suma de ventas registradas dentro del mes seleccionado.

Fuente inicial: captura manual.

Fuente futura: cubo de ventas.
