# Dashboard ejecutivo

## Objetivo

Mostrar tendencias, riesgos y oportunidades sin detalle operativo excesivo.

## Indicadores

- Venta total.
- Cumplimiento de presupuesto.
- Crecimiento.
- Conversión.
- Ticket promedio.
- Inventario crítico.
- Demanda no atendida.
- Desempeño de CEDIS.
- Cumplimiento de comercialización.
- Proveedores con incidencias.
- Valor de oportunidades abiertas.
