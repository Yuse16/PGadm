# KPIs de layout

## Indicadores

- Muebles completos.
- Posiciones ocupadas.
- Posiciones vacías.
- Productos sin stock.
- Etiquetas faltantes.
- Productos dañados.
- Muebles con promoción.
- Cambios de layout.
- Tareas pendientes.

## Futuro

- Ventas por zona.
- Conversión por mueble.
- Impacto antes y después.
