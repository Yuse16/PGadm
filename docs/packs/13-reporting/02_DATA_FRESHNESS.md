# Actualización de datos

## Cada tarjeta debe indicar

- Fuente.
- Fecha del dato.
- Hora del dato.
- Última sincronización.
- Estado de actualización.

## Estados

- Actualizado.
- Parcialmente actualizado.
- Desactualizado.
- Captura manual.
- Pendiente de confirmar.
- Sin datos.

## Regla

No debe mostrarse una cifra variable sin contexto temporal.
