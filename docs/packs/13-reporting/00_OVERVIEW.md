# Overview

## Propósito

Mostrar qué está pasando en la tienda, qué requiere atención y qué decisiones pueden mejorar ventas y operación.

## Principio

Un dashboard no debe ser una colección de gráficas decorativas.

Debe responder:

- ¿Cómo vamos?
- ¿Qué cambió?
- ¿Qué está detenido?
- ¿Qué puede generar venta?
- ¿Qué requiere acción hoy?
- ¿Qué riesgo existe?
- ¿Qué resultado tuvo una decisión?

## Audiencias

- Vendedora.
- Gerente de tienda.
- Almacén.
- CEDIS.
- Comercial.
- Dirección.
- Administrador.
