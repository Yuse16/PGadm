# Comparación entre sucursales

## Indicadores comparables

- Cumplimiento de presupuesto.
- Conversión.
- Ticket promedio.
- Pérdidas por stock.
- Cumplimiento comercialización.
- Tiempo de respuesta.
- Seguimientos.

## Regla

No mezclar aprendizajes locales.

El comparativo informa; no transforma patrones en reglas comunes automáticamente.
