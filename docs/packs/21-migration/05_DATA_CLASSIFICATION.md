# Clasificación de datos

## Oficial

Proviene de Intelisis o fuente corporativa aprobada.

## Operativo

Capturado por tienda para complementar la operación.

## Observado

Inferido o detectado por historial.

## Provisional

Se utiliza mientras se confirma el dato real.

## Sensible

Clientes, ventas, costos, usuarios y credenciales.

## Regla

Toda tabla importada debe indicar la clasificación de su fuente.
