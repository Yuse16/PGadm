# Criterios de aceptación

La migración se considera lista cuando:

1. Las fuentes están identificadas.
2. Los responsables están definidos.
3. Los datos están perfilados.
4. Existen reglas de calidad.
5. Existe mapeo versionado.
6. Se ejecuta dry run.
7. Se migran lotes en orden.
8. Se reconcilian resultados.
9. Se validan productos, inventario y layout.
10. Se aprueban usuarios y permisos.
11. Existe plan de corte.
12. Existe operación paralela.
13. Existe rollback.
14. Existe auditoría.
15. La puesta en marcha tiene soporte.
