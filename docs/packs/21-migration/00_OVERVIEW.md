# Overview

## Propósito

Convertir datos actuales dispersos en información confiable dentro de la PWA.

## Fuentes iniciales

- Intelisis.
- Cubos.
- Excel.
- Archivos de comercialización.
- Layout de Canva.
- Catálogos internos.
- Fichas técnicas.
- Clientes.
- Cotizaciones.
- Seguimientos.
- Proveedores.
- Documentos operativos.

## Principio

Migrar no significa copiar todo.

Solo deben incorporarse datos útiles, validados y con una fuente identificada.
