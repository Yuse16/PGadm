# Reglas de calidad

## Producto

- Código obligatorio.
- Descripción.
- Unidad.
- Estado.
- Categoría cuando exista.
- No duplicidad de código.

## Usuario

- Correo o identificador.
- Nombre.
- Rol.
- Sucursal.
- Estado.

## Inventario

- Código.
- Almacén.
- Cantidad numérica.
- Fecha.
- Fuente.

## Regla

Los registros inválidos se separan; no se completan por intuición.
