# Migración de layout

## Fuente inicial

Plano creado en Canva.

## Proceso

1. Importar como referencia.
2. Definir escala.
3. Crear elementos.
4. Asignar códigos.
5. Crear cuatro M1.
6. Crear rieles y posiciones.
7. Asignar productos.
8. Validar físicamente.
9. Publicar versión 1.

## Regla

La imagen se conserva como referencia, pero el layout final es estructurado.
