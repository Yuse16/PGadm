# Responsables de datos

## Roles sugeridos

- Propietario de negocio.
- Responsable operativo.
- Responsable técnico.
- Validador.
- Aprobador.
- Usuario de prueba.

## Ejemplos

### Inventario

- Fuente oficial: Intelisis.
- Responsable operativo: gerente o inventarios.
- Responsable técnico: TI o desarrollo.

### Layout

- Responsable operativo: gerente de tienda.
- Aprobador: Comercial o gerente autorizado.
