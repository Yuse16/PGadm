# Principios de migración

1. Conservar la fuente original.
2. No sobrescribir sin vista previa.
3. Distinguir datos oficiales de datos manuales.
4. Documentar transformaciones.
5. Validar con usuarios responsables.
6. Ejecutar pruebas antes del corte.
7. Mantener respaldo.
8. Reconciliar después de importar.
9. Evitar duplicados.
10. Permitir reversión.
