# Validación por muestra

## Cuando el volumen sea alto

Seleccionar:

- Productos de distintas categorías.
- Productos con cero.
- Productos con stock alto.
- Productos de CEDIS.
- Productos en M1.
- Clientes activos.
- Folios abiertos.

## Regla

La muestra complementa, no sustituye los controles automáticos.
