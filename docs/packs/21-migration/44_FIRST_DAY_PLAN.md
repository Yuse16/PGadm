# Primer día

## Antes de abrir

- Verificar acceso.
- Verificar inventario.
- Verificar layout.
- Verificar búsqueda.
- Verificar cotización.
- Verificar notificaciones.

## Durante

- Soporte disponible.
- Registrar dudas.
- Registrar errores.
- Evitar cambios grandes.
- Supervisar datos.

## Cierre

- Revisar uso.
- Revisar incidentes.
- Respaldar.
- Priorizar correcciones.
