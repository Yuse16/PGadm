# Limpieza de datos

## Acciones permitidas

- Eliminar espacios.
- Normalizar mayúsculas.
- Normalizar fechas.
- Normalizar teléfonos.
- Separar campos.
- Identificar duplicados.
- Corregir valores con aprobación.

## Acciones no automáticas

- Fusionar productos.
- Cambiar códigos.
- Cambiar líneas.
- Cambiar proveedor.
- Cambiar cliente.
- Sustituir valores oficiales.
