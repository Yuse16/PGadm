# Inventario de fuentes

## Cada fuente debe registrar

- Nombre.
- Tipo.
- Ubicación.
- Responsable.
- Fecha.
- Alcance.
- Formato.
- Sensibilidad.
- Frecuencia.
- Calidad.
- Uso.
- Estado.

## Estados

- Identificada.
- Pendiente de acceso.
- Recibida.
- En revisión.
- Validada.
- Rechazada.
- Migrada.
