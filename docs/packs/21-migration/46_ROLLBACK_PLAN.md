# Plan de reversión

## Casos

- Datos incorrectos.
- Permisos incorrectos.
- Fallo crítico.
- Importación corrupta.
- Interrupción prolongada.

## Acciones

- Desactivar módulo.
- Restaurar backup.
- Revertir lote.
- Volver a proceso manual.
- Comunicar.
- Documentar.

## Regla

La reversión no debe eliminar la evidencia del incidente.
