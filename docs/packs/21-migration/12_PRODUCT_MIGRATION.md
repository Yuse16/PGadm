# Migración de productos

## Campos

- Código.
- Descripción.
- Marca.
- Proveedor.
- Categoría.
- Línea.
- Unidad.
- Formato.
- Cobertura.
- Piezas.
- Estado.

## Validaciones

- Código único.
- Descripción no vacía.
- Unidad válida.
- Línea identificada o pendiente.
- Producto activo o inactivo.

## Regla

No eliminar productos históricos.
