# Excepciones

## Ejemplos

- Producto sin categoría.
- Proveedor sin código.
- Cliente duplicado.
- Almacén no identificado.
- Línea pendiente.
- Posición de layout sin producto.

## Tratamiento

- Aceptar temporalmente.
- Corregir antes de migrar.
- Rechazar.
- Escalar.

## Regla

Toda excepción aceptada debe tener responsable y fecha de revisión.
