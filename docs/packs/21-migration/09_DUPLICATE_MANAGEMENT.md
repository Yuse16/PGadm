# Duplicados

## Tipos

- Código duplicado.
- Cliente duplicado.
- Proveedor duplicado.
- Usuario duplicado.
- Archivo repetido.
- Folio repetido.
- Layout repetido.

## Resolución

- Mantener.
- Fusionar.
- Archivar.
- Rechazar.
- Solicitar revisión.

## Regla

Toda fusión debe conservar referencias anteriores.
