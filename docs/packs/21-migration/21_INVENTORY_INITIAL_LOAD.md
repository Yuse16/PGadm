# Carga inicial de inventario

## Flujo

1. Actualizar Excel.
2. Guardar copia.
3. Validar archivo.
4. Mapear columnas.
5. Resolver productos.
6. Resolver almacenes.
7. Crear snapshot inicial.
8. Revisar errores.
9. Aprobar.
10. Publicar.

## Regla

El snapshot inicial debe guardar fecha exacta de la fuente.
