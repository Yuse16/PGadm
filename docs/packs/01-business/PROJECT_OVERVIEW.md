# Project Overview

## Objetivo
Construir una PWA instalable para gerentes, vendedores, almacén, CEDIS y Comercial que conecte layout, inventario, comercialización, ventas, seguimiento, balanceos, juntas e IA.

## Problema
La información está dispersa entre Intelisis, cubos, Excel, PDF, correo, WhatsApp y experiencia personal.

## Resultado
Un vendedor escribe un código y obtiene producto exacto, ubicación, precio, stock tienda/CEDIS, ficha técnica, promoción, calculadora, complementos y cotización.
