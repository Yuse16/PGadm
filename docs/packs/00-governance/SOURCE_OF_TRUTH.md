# Fuentes oficiales y prioridad

1. **Intelisis**: inventario, ventas, movimientos, líneas y almacenes.
2. **Comercialización corporativa**: campañas, etiquetas, productos y acomodos.
3. **Cubos / Data Warehouse**: consulta operativa con posible retraso.
4. **Excel conectado a cubos**: medio actual de actualización.
5. **Usuarios autorizados**: validan layout, checklist, evidencias y decisiones.

## Conflictos
Si cubo, Excel, físico e Intelisis difieren, la PWA conserva Intelisis como valor oficial y registra la diferencia como alerta.
