# Ejecución de tareas

## Tipos de acción

- Imprimir etiqueta.
- Retirar etiqueta anterior.
- Cambiar muestra.
- Mover producto.
- Colocar promoción.
- Cambiar precio.
- Limpiar exhibición.
- Sustituir producto dañado.
- Completar mueble.
- Retirar producto.
- Solicitar material.
- Confirmar stock.

## Regla de avance

El porcentaje se calcula con tareas aprobadas aplicables.

## Atraso

Debe marcarse como atrasada si supera el plazo operativo esperado y aún tiene tareas pendientes.

## Responsabilidad

La PWA organiza y controla.

El gerente decide quién ejecuta cada tarea.
