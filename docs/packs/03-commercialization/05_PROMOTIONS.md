# Promociones

## Origen

Las promociones de comercialización provienen de corporativo.

## Regla de exactitud

Una promoción debe relacionarse con el producto o código exacto.

La PWA no debe sustituir automáticamente un modelo promocionado por uno parecido.

## Productos promocionables

La comercialización puede incluir:

- Pisos y recubrimientos.
- Parrillas.
- Campanas.
- Adhesivos.
- Boquillas.
- Sanitarios.
- Vanities.
- Grifería.
- Otros productos definidos por corporativo.

## Información mínima

- Campaña.
- Producto.
- Código.
- Precio o beneficio.
- Fecha de vigencia.
- Línea.
- Etiqueta.
- Zona sugerida.
- Sucursal aplicable.
