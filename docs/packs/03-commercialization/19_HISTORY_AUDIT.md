# Historial y auditoría

## Debe conservarse

- Materiales originales.
- Transcripciones.
- Conversaciones con IA.
- Acuerdos.
- Checklists.
- Versiones.
- Cambios.
- Evidencias.
- Aprobaciones.
- Fechas y horas.
- Usuarios.

## Regla

No se deben borrar versiones aprobadas.

## Consultas

- Ver comercialización de un mes.
- Ver cambios entre v1 y v2.
- Ver quién aprobó.
- Ver qué tareas quedaron incompletas.
- Ver qué se ejecutó en una ubicación.
