# Etiquetas de comercialización

## Regla principal

Las etiquetas se imprimen manualmente en la tienda.

La PWA debe indicar qué etiqueta corresponde a cada producto.

## Colores conocidos

- Producto Nuevo: dorada.
- Lujo / Medio Lujo: blanca.
- Paquete Ahorres: naranja.
- Remate: roja.
- Impulso: amarilla en el mes observado.

## Diseño variable

El color, tipografía, números o diseño pueden cambiar cada mes.

Aunque un producto continúe en promoción, la tienda puede tener que reemplazar su etiqueta para mantener uniformidad entre sucursales.

## Reemplazo mensual

Cuando llega una nueva comercialización:

- Se reemplazan todas las etiquetas indicadas para la campaña vigente.
- No se conserva una etiqueta anterior solo porque el producto sigue.
- La PWA debe generar lista de etiquetas por imprimir y cambiar.

## Validaciones

- Producto correcto.
- Código exacto.
- Precio correcto.
- Color y diseño vigentes.
- Etiqueta visible.
- Etiqueta coincidente con la muestra.
