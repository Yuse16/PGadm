# Evidencias

## Evidencias permitidas

- Fotografía.
- Nota.
- Comentario.
- Archivo.
- Confirmación manual.

## Uso

Las fotos no son obligatorias para la primera versión, pero deben soportarse.

## Relación

Cada evidencia se liga a:

- Mes.
- Versión.
- Checklist.
- Tarea.
- Ubicación.
- Producto.
- Usuario.
- Fecha y hora.
