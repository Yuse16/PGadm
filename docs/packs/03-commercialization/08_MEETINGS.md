# Juntas de comercialización

## Alcance inicial

La PWA no integrará Zoom o Teams dentro de la aplicación en la primera versión.

## Registro de junta

Cada junta puede guardar:

- Título.
- Fecha y hora.
- Plataforma.
- Enlace.
- Audio.
- PDF relacionados.
- Texto opcional.
- Notas.
- Transcripción.
- Chat con IA.
- Acuerdos.

## Uso

El gerente puede grabar el audio desde otro dispositivo y subirlo posteriormente.
