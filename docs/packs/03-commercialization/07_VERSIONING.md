# Versionado

## Versiones

Cada comercialización mensual comienza como `v1`.

Si llega un complemento o corrección:

- Se crea `v2`.
- Después `v3`, si fuera necesario.

## Vista de nueva versión

La nueva versión debe mostrar únicamente los cambios nuevos respecto a la versión anterior.

## Historial

- La v1 nunca se elimina.
- Todas las versiones siguen disponibles para consulta.
- Debe poder compararse versión actual contra versión anterior.

## Ejemplos de cambios

- Producto agregado.
- Producto retirado.
- Etiqueta modificada.
- Precio corregido.
- Zona cambiada.
- Instrucción reemplazada.
- Checklist actualizado.
