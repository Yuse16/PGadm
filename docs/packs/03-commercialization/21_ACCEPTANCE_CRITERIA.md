# Criterios de aceptación

El módulo se considera funcional cuando:

1. Permite navegar por mes anterior, actual y siguiente.
2. Permite crear el mes siguiente con `+`.
3. Admite varios PDF y audios por mes.
4. Guarda fecha y hora de cada elemento.
5. Transcribe audios.
6. Analiza PDF, transcripción y texto.
7. Genera borrador editable.
8. Permite conversar con IA.
9. Requiere aprobación.
10. Maneja v1, v2 y versiones posteriores.
11. Muestra únicamente cambios nuevos en versiones nuevas.
12. Relaciona tareas con layout.
13. Conserva historial completo.
14. Muestra avance y atraso.
15. Nunca reemplaza una regla corporativa con una suposición.
