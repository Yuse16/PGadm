# Chat de IA de comercialización

## Propósito

Permitir que el usuario converse con la IA antes de aprobar acuerdos y checklist.

## Ejemplos

- ¿Qué quisieron decir con “poner en entrada”?
- ¿Qué muebles de Nogalera pueden cumplir esta indicación?
- ¿Qué productos exactos mencionaron?
- ¿Qué cambió frente al PDF anterior?
- ¿Qué dudas debemos aclarar?
- ¿Qué etiquetas se reemplazan?

## Contexto

El chat debe limitarse al mes y versión seleccionados, pero puede consultar historial si el usuario lo pide.

## Persistencia

Toda la conversación se guarda con:

- Fecha.
- Hora.
- Usuario.
- Mes.
- Versión.
- Documentos utilizados.
