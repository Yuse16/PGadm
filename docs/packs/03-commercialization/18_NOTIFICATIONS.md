# Notificaciones

## Eventos

- Nuevo mes creado.
- Nuevo PDF.
- Nuevo audio.
- Transcripción terminada.
- Análisis listo.
- Checklist pendiente de aprobación.
- Complemento recibido.
- Nueva versión creada.
- Comercialización atrasada.
- Tarea bloqueada.
- Comercialización completada.

## Reglas

Las notificaciones deben incluir:

- Mes.
- Versión.
- Motivo.
- Acción sugerida.
- Enlace directo.
