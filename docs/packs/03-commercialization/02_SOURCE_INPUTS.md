# Entradas de información

## Fuentes admitidas

Una comercialización mensual puede contener:

- Uno o varios PDF.
- Uno o varios audios.
- Texto pegado manualmente.
- Resumen generado por otra herramienta.
- Notas del gerente.
- Instrucciones del correo.
- Complementos posteriores.
- Cambios completos.
- Conversaciones con la IA.

## Metadatos obligatorios

Cada elemento debe guardar:

- Tipo de contenido.
- Nombre o título.
- Fecha.
- Hora.
- Usuario que lo agregó.
- Mes y año de comercialización.
- Versión relacionada.
- Estado de procesamiento.

## Regla

El texto es opcional.

Si existe audio, la PWA debe poder transcribirlo internamente.
