# Relación con el layout

## Principio

La instrucción corporativa puede ser general, pero cada tienda tiene un layout diferente.

Ejemplo:

`Colocar en la entrada`

No significa la misma coordenada en todas las sucursales.

## Comportamiento

La PWA debe:

1. Detectar la zona indicada.
2. Consultar el layout real de la tienda.
3. Proponer ubicaciones compatibles.
4. Mostrar productos y stock.
5. Permitir al gerente seleccionar la ubicación final.
6. Guardar la decisión.

## Acciones desde layout

- Ver tareas de comercialización.
- Resaltar muebles afectados.
- Abrir producto.
- Consultar stock.
- Marcar tarea completada.
- Adjuntar evidencia.
