# Navegación mensual

## Encabezado

La pantalla debe mostrar:

`Mes anterior (JUNIO) — Mes actual (JULIO) — +`

## Botón `+`

Permite crear anticipadamente el mes siguiente cuando llega información adelantada.

Después de crearlo:

`Mes anterior (JUNIO) — Mes actual (JULIO) — Mes siguiente (AGOSTO)`

## Cambio automático de mes

Cuando inicia un nuevo mes:

- El mes nuevo se convierte en Mes actual.
- El mes anterior pasa a historial.
- El Mes actual abre limpio si no se agregó contenido anticipadamente.
- Si ya existía contenido como Mes siguiente, se conserva.

## Historial

El usuario puede seguir retrocediendo por mes y año.
