# Criterios de aceptación

El sistema de calidad y operación se considera listo cuando:

1. Existen ambientes separados.
2. Hay pruebas unitarias.
3. Hay pruebas de integración.
4. Hay pruebas end to end.
5. Se prueban permisos.
6. Se prueban cálculos.
7. Se prueban importaciones.
8. Existe plan piloto.
9. Existe liberación gradual.
10. Existe rollback.
11. Existe monitoreo.
12. Existen respaldos.
13. Se prueba restauración.
14. Existe soporte.
15. Se documentan incidentes.
16. Existe continuidad sin PWA.
17. Cada función tiene definición de terminado.
