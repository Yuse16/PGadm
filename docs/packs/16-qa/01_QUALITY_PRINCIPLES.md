# Principios de calidad

1. Probar resultados, no solo botones.
2. Validar datos antes y después de una acción.
3. Probar permisos en servidor.
4. No usar producción como ambiente de pruebas.
5. Conservar evidencia de fallas.
6. Repetir pruebas después de cada corrección.
7. Automatizar procesos repetitivos.
8. Probar escenarios normales y extremos.
9. No ocultar errores.
10. Liberar gradualmente.
