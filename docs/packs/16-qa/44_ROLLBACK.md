# Reversión

## Casos

- Error crítico.
- Migración fallida.
- Pérdida de acceso.
- Cálculo incorrecto.
- Integración inestable.

## Plan

- Desactivar feature flag.
- Restaurar versión.
- Restaurar base cuando sea necesario.
- Comunicar.
- Documentar.
- Corregir.

## Regla

Toda liberación crítica debe tener un plan de reversión probado.
