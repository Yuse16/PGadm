# Pruebas de importación

## Casos

- Archivo correcto.
- Hoja incorrecta.
- Columna faltante.
- Código duplicado.
- Almacén desconocido.
- Cantidad no numérica.
- Producto ausente.
- Archivo repetido.
- Archivo grande.
- Interrupción.
- Reintento.

## Resultado

La aplicación debe explicar qué importó y qué rechazó.
