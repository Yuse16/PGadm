# Criterios de liberación

## Requisitos

- Pruebas críticas aprobadas.
- Sin errores críticos abiertos.
- Permisos validados.
- Migraciones probadas.
- Respaldo disponible.
- Plan de reversión.
- Notas de versión.
- Responsable.
- Monitoreo activo.

## Regla

Una fecha comprometida no justifica liberar una versión insegura.
