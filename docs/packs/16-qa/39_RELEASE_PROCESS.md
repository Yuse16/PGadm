# Proceso de liberación

1. Congelar versión.
2. Ejecutar pruebas.
3. Revisar migraciones.
4. Crear respaldo.
5. Publicar en piloto.
6. Validar.
7. Publicar producción.
8. Ejecutar smoke tests.
9. Monitorear.
10. Cerrar liberación.

## Registro

- Versión.
- Cambios.
- Responsable.
- Fecha.
- Resultado.
