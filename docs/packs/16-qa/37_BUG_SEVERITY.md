# Severidad de errores

## Crítica

- Pérdida de datos.
- Acceso no autorizado.
- Cálculo económico incorrecto.
- Sistema inaccesible.
- Acción en sucursal incorrecta.

## Alta

- Flujo principal bloqueado.
- Cotización incorrecta.
- Importación fallida.
- Aprobación incorrecta.

## Media

- Función secundaria.
- Error con alternativa.

## Baja

- Texto.
- Alineación.
- Mejora visual.
