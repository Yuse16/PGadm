# Datos de prueba

## Productos ficticios

- Pisos.
- Sanitarios.
- Vanities.
- Adhesivos.
- Parrillas.
- Grifería.

## Escenarios de stock

- Cero en tienda.
- Alto en CEDIS.
- Stock insuficiente.
- Producto sin datos técnicos.
- Producto con promoción.
- Remate sin stock.
- Impulso temporal.

## Regla

Los datos de prueba deben ser claramente identificables.
