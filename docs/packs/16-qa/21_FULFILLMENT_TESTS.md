# Pruebas de apartados y entregas

## Casos

- Crear folio.
- Imprimir etiqueta.
- Guardar ubicación.
- Recepción parcial.
- Listo para recoger.
- Cliente contactado.
- Entrega parcial.
- Entrega completa.
- Más de 20 días.
- Cancelación.
- Liberación.

## Regla

El folio permanece abierto mientras exista cantidad pendiente.
