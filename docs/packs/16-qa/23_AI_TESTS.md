# Pruebas de IA

## Casos

- Pregunta con fuente.
- Pregunta sin fuente.
- Conflicto entre datos.
- Stock desactualizado.
- Código inexistente.
- Recomendación.
- Rechazo.
- Corrección.
- Documento ambiguo.
- Intento de acción no permitida.

## Validación

La IA debe reconocer incertidumbre y no inventar.
