# Overview

La seguridad debe aplicarse en interfaz, backend, base de datos, archivos, integraciones y operación.

## Activos protegidos

- Usuarios y sesiones.
- Clientes y oportunidades.
- Ventas y cotizaciones.
- Inventario y layout.
- Documentos y audios.
- Credenciales e integraciones.
- Reglas y conocimiento.
- Datos separados por sucursal.
