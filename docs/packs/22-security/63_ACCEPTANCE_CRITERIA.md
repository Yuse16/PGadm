# Criterios de aceptación

1. Clasificación de datos.
2. Menor privilegio.
3. RLS probado.
4. Sesiones revocables.
5. Secretos protegidos.
6. Archivos privados.
7. IA con contexto mínimo.
8. Control de prompt injection.
9. Exportaciones controladas.
10. Auditoría.
11. Alertas.
12. Respuesta a incidentes.
13. Backups restaurables.
14. Retención.
15. Revisión de proveedores.
