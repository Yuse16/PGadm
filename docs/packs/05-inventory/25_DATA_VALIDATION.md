# Validación de datos

## Validaciones mínimas

- Código no vacío.
- Almacén válido.
- Cantidad numérica.
- No duplicar producto/almacén sin regla.
- Fecha válida.
- Unidad conocida o marcada como desconocida.
- Línea actual no inferida.
- Tienda y CEDIS seleccionados.

## Errores

La PWA debe mostrar:

- Fila.
- Campo.
- Valor.
- Motivo.
- Acción sugerida.
