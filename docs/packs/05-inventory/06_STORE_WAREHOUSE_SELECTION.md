# Selección de tienda y CEDIS

## Sucursal inicial

- Tienda: `116NOG-PGM`.
- CEDIS: `106SAL-PGM`.

## Regla

La aplicación debe leer todos los almacenes detectados en el archivo y permitir seleccionar:

- Tienda principal.
- CEDIS relacionado.

## Validación

La PWA debe mostrar:

- Código detectado.
- Nombre detectado.
- Tipo asignado.
- Fecha de última información.
- Número de productos encontrados.

## Restricción

Nunca debe mezclar existencias de otras sucursales con la tienda seleccionada.
