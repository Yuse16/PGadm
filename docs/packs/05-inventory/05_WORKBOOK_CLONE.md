# Copia operativa del Excel

## Regla

No modificar el archivo original utilizado por la tienda.

## Propuesta

Crear una copia operativa:

`Inventario_Cubos_Original.xlsx`

a:

`Control_Operativo_Nogalera.xlsx`

## Objetivo

Conservar la conexión existente y agregar hojas limpias para la PWA.

## Hojas propuestas

- `00_CONFIGURACION`
- `10_INVENTARIO_MAESTRO`
- `11_CAMBIOS_STOCK`
- `12_PRODUCTOS_CON_STOCK_CEDIS`
- `13_STOCK_BAJO`
- `14_SIN_STOCK`
- `15_PRODUCTOS_EXHIBIDOS`
- `90_EXPORT_INVENTARIO`
- `91_EXPORT_CAMBIOS`
