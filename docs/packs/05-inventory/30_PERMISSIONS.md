# Permisos

## Vendedora

- Consultar stock.
- Ver historial básico.
- Crear oportunidad.
- Solicitar CEDIS.
- Reportar diferencia.

## Gerente

- Importar archivo.
- Seleccionar tienda/CEDIS.
- Revisar errores.
- Confirmar observaciones.
- Ver historial completo.
- Configurar umbrales.

## Almacén

- Consultar.
- Reportar conteo.
- Reportar recepción.
- Reportar daño.
- Participar en solicitudes.

## Comercial

- Ver información agregada.
- Comparar sucursales.
- Revisar alertas.
