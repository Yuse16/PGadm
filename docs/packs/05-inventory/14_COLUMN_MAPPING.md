# Mapeo de columnas

## Objetivo

Permitir que el importador se adapte a variaciones de Excel.

## Campos requeridos

- Código de producto.
- Descripción.
- Almacén.
- Existencia.

## Campos opcionales

- Línea.
- Marca.
- Proveedor.
- Familia.
- Unidad.
- Formato.
- Precio.
- Fecha.

## Reglas

- El usuario puede confirmar el mapeo.
- El sistema guarda la plantilla por tipo de archivo.
- Si falta un campo requerido, no se importa silenciosamente.
