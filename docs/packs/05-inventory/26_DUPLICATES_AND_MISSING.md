# Duplicados y faltantes

## Duplicados

Pueden existir por:

- Varias ubicaciones.
- Varias unidades.
- Varias líneas de movimiento.
- Error de archivo.

## Regla

No sumar automáticamente sin entender la estructura.

## Productos faltantes

Si un producto desaparece del archivo:

- Marcar como ausente.
- No asignar stock cero automáticamente.
- Comparar con estructura del reporte.
- Solicitar revisión.
