# Prioridad de fuentes

## Orden

1. Intelisis.
2. Cubo procesado.
3. Excel conectado al cubo.
4. Conteo físico reportado.
5. Captura manual.

## Conflicto

Si Intelisis muestra 10, el cubo 12 y físicamente hay 8:

- Intelisis permanece como valor oficial.
- La PWA registra diferencias.
- La PWA no reemplaza automáticamente el valor oficial.
- El gerente puede registrar una observación física.
- La incidencia queda visible para seguimiento.
