# IA para inventario

## Puede recomendar

- Revisar producto.
- Solicitar balanceo.
- Mover exhibición.
- Sustituir muestra.
- Preparar solicitud.
- Detectar demanda.
- Explicar cambios.

## Debe considerar

- Stock tienda.
- Stock CEDIS.
- Línea.
- Comercialización.
- Layout.
- Solicitudes de clientes.
- Historial local.

## No puede

- Inventar causa de movimiento.
- Cambiar stock oficial.
- Crear una línea.
- Prometer entrega.
- Modificar layout sin aprobación.
