# Pipeline de importación

## Etapas

1. Carga del archivo.
2. Detección de formato.
3. Lectura de hojas.
4. Detección de encabezados.
5. Identificación de almacenes.
6. Normalización de códigos.
7. Validación de cantidades.
8. Selección tienda/CEDIS.
9. Comparación con carga anterior.
10. Persistencia.
11. Generación de alertas.
12. Resumen final.

## Resultado

- Productos procesados.
- Productos nuevos.
- Productos modificados.
- Productos sin cambios.
- Errores.
- Almacenes detectados.
