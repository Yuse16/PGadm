# Observaciones y ajustes manuales

## Permitido

Registrar observaciones manuales:

- Conteo físico.
- Producto dañado.
- Producto apartado.
- Ubicación incorrecta.
- Etiqueta faltante.
- Diferencia detectada.

## No permitido

Cambiar el stock oficial de Intelisis desde la PWA.

## Auditoría

Cada observación guarda:

- Usuario.
- Fecha y hora.
- Cantidad observada.
- Evidencia.
- Comentario.
