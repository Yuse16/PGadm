# Integración con layout

## Al tocar un mueble

Mostrar:

- Productos.
- Stock tienda.
- Stock CEDIS.
- Línea.
- Precio.
- Último cambio.
- Alertas.
- Recomendaciones.

## Cambio de inventario

Una actualización de stock:

- No cambia automáticamente el producto del layout.
- Marca posición para revisión.
- Sugiere reemplazo compatible.
- Espera confirmación.

## Historial

Cada posición conserva:

- Producto actual.
- Productos anteriores.
- Fechas.
- Motivos.
- Resultados.
