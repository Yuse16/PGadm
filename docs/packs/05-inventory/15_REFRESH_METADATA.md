# Metadatos de actualización

## Debe mostrarse

- Archivo.
- Fecha de carga.
- Hora de carga.
- Fecha interna del reporte.
- Usuario.
- Tienda.
- CEDIS.
- Registros.
- Estado.
- Advertencias.

## Indicador

La PWA debe diferenciar:

- Archivo cargado recientemente.
- Datos del cubo posiblemente antiguos.
- Información incompleta.
