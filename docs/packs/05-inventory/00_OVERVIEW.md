# Overview

## Propósito

Dar a la PWA una fuente confiable de inventario para tienda y CEDIS, mantener historial de cambios y alimentar ventas, layout, comercialización, balanceos y recomendaciones de IA.

## Fuente actual

La tienda utiliza un archivo Excel conectado a cubos.

El usuario abre el archivo y ejecuta `Actualizar` para reflejar entradas, ventas y movimientos procesados.

## Fuente oficial

Intelisis es la fuente oficial.

El cubo y Excel son fuentes de consulta derivadas.

## Objetivos de la primera versión

- Importar inventario desde Excel conectado.
- Detectar almacenes disponibles.
- Seleccionar tienda y CEDIS.
- Mostrar existencia por producto.
- Guardar solo cambios.
- Relacionar inventario con layout.
- Alimentar búsqueda comercial.
- Generar alertas y recomendaciones.
- Preparar una futura conexión autorizada.
