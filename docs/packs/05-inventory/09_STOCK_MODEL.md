# Modelo de stock

## Stock conocido actualmente

El cubo actual muestra existencia total.

## Campos deseados

- Existencia total.
- Reservado.
- Disponible.
- Backorder.
- Pendiente.
- Dañado.
- En revisión.

## Regla inicial

Mientras solo exista existencia total:

- Mostrar `Existencia reportada`.
- No llamar `Disponible real`.
- Mostrar advertencia en pedidos grandes.
- No descontar reservas por suposición.
