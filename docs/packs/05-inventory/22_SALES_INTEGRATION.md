# Integración con ventas

## Producto consultado

Debe mostrar:

- Existencia tienda.
- Existencia CEDIS.
- Cajas y m².
- Entrega.
- Alternativas.
- Última actualización.

## Oportunidad

Si el cliente requiere más de lo disponible:

- Calcular faltante.
- Consultar CEDIS.
- Crear solicitud.
- Guardar valor potencial.
- Dar seguimiento.

## Regla

La disponibilidad debe explicarse con honestidad.
