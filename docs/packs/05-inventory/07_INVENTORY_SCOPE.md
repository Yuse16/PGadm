# Alcance inicial del inventario

## Familias prioritarias

La primera versión se enfocará en:

- Pisos y recubrimientos.
- Tazas.
- Lavabos.
- Pedestales.
- Asientos para baño.
- Espejos.
- Vanities.
- Parrillas.
- Campanas.

## Condición inicial

Mostrar especialmente productos con stock en CEDIS y productos relevantes para venta o exhibición.

## Expansión futura

- Grifería.
- Boilers.
- Adhesivos.
- Boquillas.
- Fachaletas.
- Mallas.
- Jacuzzis.
- Refacciones.
- Herramientas.
