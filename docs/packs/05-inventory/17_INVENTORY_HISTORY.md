# Historial de inventario

## Vista por producto

El usuario puede consultar:

- Línea de tiempo.
- Existencia por fecha.
- Cambios.
- Tienda.
- CEDIS.
- Observaciones.
- Relación con layout.
- Relación futura con ventas.

## Regla

El historial no se borra al cargar un nuevo Excel.

## Uso

- Detectar velocidad de salida.
- Detectar reposición.
- Analizar demanda.
- Apoyar balanceos.
- Explicar recomendaciones.
