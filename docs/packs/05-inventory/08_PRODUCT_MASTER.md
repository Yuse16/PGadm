# Maestro de productos

## Campos mínimos

- Código.
- Descripción.
- Marca.
- Proveedor.
- Familia.
- Categoría.
- Línea actual.
- Formato.
- Unidad.
- Piezas por caja.
- m² por caja.
- Cantidad por tarima.
- Precio por m².
- Precio por caja.
- Ficha técnica.
- Imagen.
- Estado.

## Reglas

- El código identifica el producto exacto.
- La línea se vuelve a leer en cada actualización.
- La PWA no debe inventar campos faltantes.
- Los datos técnicos pueden complementarse con fuentes oficiales.
