# Flujo actual del Excel

## Operación diaria

1. Abrir archivo conectado al cubo.
2. Ejecutar `Actualizar`.
3. Esperar que termine.
4. Revisar existencias.
5. Identificar lo vendido, recibido o modificado.
6. Usar el resultado para preparar balanceos.

## Comportamiento esperado en la PWA

- Registrar fecha y hora de carga.
- Identificar archivo.
- Detectar hojas.
- Detectar almacenes.
- Validar columnas.
- Importar datos.
- Comparar contra última carga.
- Guardar solo productos modificados.
- Mostrar resumen.
