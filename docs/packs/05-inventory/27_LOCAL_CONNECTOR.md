# Conector local

## Objetivo futuro cercano

Automatizar:

1. Abrir archivo.
2. Actualizar conexiones.
3. Esperar finalización.
4. Guardar.
5. Extraer tablas planas.
6. Enviar a la PWA.
7. Registrar resultado.

## Requisitos

- Computadora autorizada.
- Usuario con acceso al cubo.
- Archivo conectado.
- Carpeta controlada.
- Credenciales no expuestas.

## Restricción

La PWA web no debe intentar conectarse directamente a una IP interna desde internet.
