# Criterios de aceptación

El módulo se considera funcional cuando:

1. Importa Excel.
2. Detecta almacenes.
3. Permite seleccionar tienda y CEDIS.
4. Lee código, descripción y existencia.
5. Valida errores.
6. Guarda metadatos.
7. Compara contra carga anterior.
8. Guarda solo cambios.
9. Muestra stock por tienda y CEDIS.
10. Relaciona stock con layout.
11. Alimenta búsqueda de ventas.
12. Genera alertas.
13. No altera el valor oficial.
14. Conserva historial.
15. Está preparado para cambiar de fuente.
