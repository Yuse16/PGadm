# Integración con comercialización

## Uso

El inventario ayuda a ejecutar campañas.

## Reglas

- Producto exacto de campaña.
- Verificar stock tienda.
- Verificar stock CEDIS.
- Priorizar ubicación según reglas aprobadas.
- Generar tarea si falta stock.
- No sustituir modelo sin autorización.

## Impulso

La línea se vuelve a leer cada mes.

La etiqueta y promoción se aplican según comercialización vigente.
