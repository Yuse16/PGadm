# Datos offline

## Permitido

- Layout publicado.
- Productos consultados recientemente.
- Fichas técnicas.
- Cotizaciones en borrador.
- Clientes recientes.
- Tareas.
- Notas.

## No recomendado

- Stock considerado definitivo.
- Autorizaciones.
- Cambios críticos.
- Reglas corporativas sin sincronizar.

## Regla

Mostrar siempre fecha de última sincronización.
