# Modelo de inventario

## InventorySnapshot

Representa una carga completa de una fuente.

## InventorySnapshotItem

Representa un producto por almacén.

## InventoryChange

Representa una diferencia entre cargas.

## InventoryObservation

Representa un conteo o nota física.

## Regla

El snapshot conserva fotografía lógica de la fuente y el cambio conserva la diferencia.
