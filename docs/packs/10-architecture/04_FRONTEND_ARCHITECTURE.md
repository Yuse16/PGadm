# Arquitectura frontend

## Stack sugerido

- Next.js.
- TypeScript.
- Tailwind CSS.
- Componentes accesibles.
- PWA.
- Estado remoto con caché.
- Formularios tipados.
- Validación compartida.

## Capas

- `app/`
- `features/`
- `components/`
- `lib/`
- `services/`
- `hooks/`
- `types/`
- `styles/`

## Regla

La lógica de negocio no debe quedar embebida en componentes visuales.
