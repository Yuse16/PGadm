# Autorización

## Modelo

RBAC con permisos específicos.

## Ejemplos

- `inventory.read`
- `inventory.import`
- `layout.edit`
- `sales.capture_own`
- `sales.edit_all`
- `commercialization.approve`
- `supply.accept`
- `ai.manage_rules`

## Regla

La interfaz oculta acciones no permitidas, pero el servidor también debe validarlas.
