# Arquitectura PWA

## Requisitos

- Manifest.
- Service worker.
- Iconos.
- Instalación.
- Caché.
- Pantalla de carga.
- Actualización controlada.
- Modo offline parcial.

## Estrategia

- Shell de aplicación en caché.
- Datos recientes de lectura.
- Cola de borradores offline.
- Sincronización al recuperar conexión.
