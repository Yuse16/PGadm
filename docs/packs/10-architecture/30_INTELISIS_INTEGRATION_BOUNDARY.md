# Límite de integración con Intelisis

## Permitido inicialmente

- Importar Excel autorizado.
- Leer exportaciones.
- Guardar referencias externas.
- Preparar información para captura manual.

## No permitido inicialmente

- Escribir en SQL.
- Extraer credenciales.
- Automatizar interfaz sin autorización.
- Modificar datos oficiales.
- Ejecutar movimientos.

## Futuro

Solo mediante aprobación de TI y acceso de solo lectura o API autorizada.
