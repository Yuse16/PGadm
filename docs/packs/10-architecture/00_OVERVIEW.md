# Overview

## Objetivo

Definir una arquitectura que permita desarrollar la PWA sin acoplarla a una sola sucursal, un solo archivo Excel, un solo proveedor de IA o una sola forma de integración con Intelisis.

## Principios

- Modularidad.
- Separación por dominio.
- Multi-sucursal.
- Seguridad por roles.
- Historial auditable.
- Sincronización progresiva.
- Fuentes de datos reemplazables.
- IA desacoplada.
- PWA instalable.
- Evolución sin rehacer el sistema.
