# Almacenamiento de archivos

## Tipos

- PDF.
- Audio.
- Imagen.
- Cotización.
- Evidencia.
- Ficha técnica.
- Exportación.
- Layout de referencia.

## Estructura sugerida

```text
organization/
  store/
    module/
      year/
        month/
```

## Reglas

- URLs privadas.
- Acceso temporal.
- Metadatos.
- Antivirus cuando sea posible.
- Límites de tamaño.
