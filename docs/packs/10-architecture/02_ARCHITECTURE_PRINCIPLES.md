# Principios de arquitectura

1. La lógica de negocio no debe depender de la interfaz.
2. La fuente de datos debe poder cambiarse mediante adaptadores.
3. Cada sucursal debe estar aislada por `store_id`.
4. Toda acción importante debe guardar historial.
5. La IA nunca debe ser la única fuente de verdad.
6. Los archivos deben procesarse de forma asíncrona.
7. Los permisos deben aplicarse también en servidor.
8. El sistema debe tolerar datos incompletos.
9. El layout debe ser estructurado, no una imagen estática.
10. Los módulos deben comunicarse mediante eventos y contratos claros.
