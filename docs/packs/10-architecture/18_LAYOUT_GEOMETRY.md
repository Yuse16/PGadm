# Geometría del layout

## Sistema

Coordenadas relativas o normalizadas.

## Reglas

- Evitar depender de píxeles absolutos.
- Guardar escala.
- Permitir zoom.
- Permitir paneo.
- Mantener proporción.
- Soportar rotación.
- Mantener capas.

## Formato sugerido

Valores entre 0 y 1 o unidades lógicas del lienzo.
