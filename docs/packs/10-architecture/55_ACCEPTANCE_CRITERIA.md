# Criterios de aceptación

La arquitectura se considera lista cuando:

1. Separa módulos.
2. Soporta varias sucursales.
3. Aplica permisos en servidor.
4. Usa adaptadores de integración.
5. Versiona layout y conocimiento.
6. Conserva auditoría.
7. Procesa archivos en segundo plano.
8. Tolera modo offline parcial.
9. Maneja conflictos.
10. Está preparada para Intelisis futuro.
11. Está preparada para varios modelos IA.
12. Puede crecer sin rehacer módulos.
