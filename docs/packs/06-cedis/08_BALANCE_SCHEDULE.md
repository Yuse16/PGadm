# Programación de balanceos

## Regla observada en Saltillo

- Solicitud el martes → movimiento físico el miércoles.
- Solicitud el viernes → movimiento físico el sábado.

## Preferencia

Se recomienda solicitar por la mañana, aunque puede hacerse durante el día.

## PWA

Debe permitir configurar por tienda:

- Días de solicitud.
- Días de entrega.
- Hora límite.
- Recordatorios.
- Excepciones.
