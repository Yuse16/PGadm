# Normalización de demanda

## Concepto

Una necesidad no se considera resuelta solo porque se envió mercancía una vez.

## La PWA debe observar

- Solicitudes pendientes.
- Stock recibido.
- Nuevas solicitudes.
- Frecuencia de venta.
- Tiempo sin volver a cero.
- Próxima llegada de proveedor.

## Resultado

La alerta puede cambiar a:

- Activa.
- Mejorando.
- Normalizada.
- Reincidente.

## Pendiente

Definir umbrales exactos mediante uso real.
