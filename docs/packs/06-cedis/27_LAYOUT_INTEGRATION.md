# Integración con layout

## Desde una ubicación

El usuario puede:

- Ver stock.
- Detectar producto sin existencia.
- Preparar balanceo.
- Ver solicitud activa.
- Ver fecha estimada.
- Ver chat.
- Marcar producto para revisión.

## Regla

La llegada de mercancía no cambia automáticamente la exhibición.

La PWA puede recomendar restaurar o mejorar la posición.
