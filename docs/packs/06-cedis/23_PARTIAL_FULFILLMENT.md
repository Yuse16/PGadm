# Cumplimiento parcial

## Caso

CEDIS acepta menos cantidad que la solicitada.

## Comportamiento

- Mantener cantidad original.
- Registrar cantidad aceptada.
- Registrar cantidad pendiente.
- Mantener motivo.
- Decidir si la necesidad sigue activa.
- Actualizar cliente u oportunidad.

## Regla

No cerrar si la necesidad comercial continúa.
