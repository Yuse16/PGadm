# Fuente oficial

## Intelisis

Intelisis es la fuente oficial de:

- Existencia.
- Almacén.
- Movimiento.
- Solicitud capturada.
- Autorización.
- Recepción.

## PWA

La PWA funciona como capa de:

- Detección.
- Recomendación.
- Comunicación.
- Seguimiento.
- Explicación.
- Historial.

## Regla

Un estado operativo en la PWA no sustituye el movimiento oficial en Intelisis.
