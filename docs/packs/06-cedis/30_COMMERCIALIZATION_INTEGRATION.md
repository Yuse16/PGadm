# Integración con comercialización

## Prioridad

Un producto en comercialización puede requerir abastecimiento prioritario.

## PWA

Debe:

- Detectar producto de campaña.
- Verificar stock.
- Relacionar mueble.
- Crear tarea.
- Preparar solicitud.
- Mostrar riesgo de incumplimiento.

## Restricción

No sustituir el producto exacto de campaña sin aprobación.
