# Integración con inventario

## Datos usados

- Stock tienda.
- Stock CEDIS.
- Historial.
- Línea.
- Cantidad por tarima.
- Producto exhibido.
- Cambios recientes.

## Regla

La recomendación debe mostrar la fecha de la información.

## Cambio

Si el stock cambia antes de aprobar:

- Recalcular.
- Mostrar diferencia.
- Solicitar revisión.
