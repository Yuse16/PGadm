# Reglas de respuesta

## CEDIS puede

- Aceptar.
- Modificar cantidad.
- Rechazar.
- Indicar fecha.
- Sugerir alternativa.
- Pedir aclaración.

## Motivos sugeridos

- Stock insuficiente.
- Mercancía comprometida.
- Próxima llegada.
- Volumen insuficiente.
- Restricción de tarima.
- Capacidad logística.
- Decisión comercial.
- Producto no balanceable.
- Otro.

## Regla

La respuesta debe quedar ligada a usuario, fecha y hora.
