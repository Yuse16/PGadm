# Consulta a otra plaza

## Regla observada

Monterrey se considera cuando:

- el producto no está disponible en Saltillo,
- y el valor de la operación es al menos $10,000 MXN.

## PWA

Debe mostrar esta ruta solo cuando se cumplan las condiciones configuradas.

## Pendiente

Confirmar:

- monto vigente,
- costos,
- autorización,
- tiempo de entrega,
- productos aplicables.
