# Reglas de recomendación

## Regla inicial

Para pisos y recubrimientos:

### Tienda en cero

Si:

- tienda = 0,
- CEDIS > 0,
- producto no es Remate Ocasión,

la PWA debe generar una recomendación de alta prioridad.

### Tienda con 1 a 5 unidades

Si:

- tienda entre 1 y 5,
- CEDIS > 0,
- producto no es Remate Ocasión,

la PWA debe recomendar revisión de balanceo.

## Factores adicionales

- Solicitudes de clientes.
- Ventas recientes.
- Stock histórico.
- Producto exhibido.
- Comercialización vigente.
- Cantidad por tarima.
- Frecuencia de proveedor.
- Oportunidad económica.
