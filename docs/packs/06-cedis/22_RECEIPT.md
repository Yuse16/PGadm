# Recepción en tienda

## Validación

- Producto correcto.
- Código correcto.
- Cantidad.
- Condición visible.
- Fecha.
- Responsable.

## Resultado

- Recibida completa.
- Recibida con diferencia.
- Recibida con daño.
- Pendiente de revisión.

## Evidencia

Puede incluir:

- Fotografía.
- Nota.
- Documento.
- Firma o confirmación.
