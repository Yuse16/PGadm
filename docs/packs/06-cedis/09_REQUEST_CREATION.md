# Creación de solicitud

## Formas de origen

- Recomendación automática.
- Solicitud manual.
- Oportunidad de venta.
- Cliente esperando.
- Comercialización.
- Producto exhibido sin stock.
- Demanda creciente.

## Datos mínimos

- Tienda.
- CEDIS.
- Producto.
- Código.
- Línea.
- Cantidad.
- Stock tienda.
- Stock CEDIS.
- Cantidad por tarima.
- Motivo.
- Prioridad.
- Fecha requerida.
- Valor potencial.
- Solicitante.
