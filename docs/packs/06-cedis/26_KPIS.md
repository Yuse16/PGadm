# Indicadores

## Operativos

- Tiempo de respuesta.
- Tiempo de autorización.
- Tiempo de tránsito.
- Cumplimiento de cantidad.
- Solicitudes abiertas.
- Solicitudes atrasadas.

## Comerciales

- Valor potencial atendido.
- Ventas recuperadas.
- Ventas perdidas por stock.
- Clientes esperando.
- Conversión después de surtir.

## Abastecimiento

- Productos reincidentes.
- Frecuencia de cero.
- Surtido por tienda.
- Incrementos sugeridos a proveedor.
