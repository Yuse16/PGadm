# Criterios de aceptación

El módulo se considera funcional cuando:

1. Detecta candidatos.
2. Respeta familias balanceables.
3. Respeta líneas no resurtibles.
4. Muestra stock tienda/CEDIS.
5. Considera tarima.
6. Permite solicitud manual y automática.
7. Maneja estados completos.
8. Tiene chat.
9. Liga solicitudes con ventas.
10. Permite aceptar, modificar y rechazar.
11. Registra tránsito.
12. Registra recepción.
13. Conserva historial.
14. Genera notificaciones.
15. Aprende demanda por sucursal.
16. No sustituye autorización de Intelisis.
