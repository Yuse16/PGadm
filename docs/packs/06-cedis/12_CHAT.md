# Chat por solicitud

## Participantes

- Gerente de tienda.
- Gerente de CEDIS.
- Jefes de almacén.
- Jefe comercial.
- Otros perfiles autorizados.

## Funciones

- Mensajes.
- Archivos.
- Fotografías.
- Comentarios.
- Menciones.
- Respuestas.
- Historial.

## Contexto visible

El chat debe mostrar siempre:

- Producto.
- Código.
- Cantidad.
- Stock.
- Estado.
- Fecha requerida.
- Valor potencial.
