# Integración con ventas

## Desde cotización

Puede crearse una solicitud con:

- Cliente.
- Producto.
- Cantidad.
- Valor.
- Fecha.
- Vendedora.

## Desde búsqueda

Si tienda no alcanza y CEDIS tiene stock:

- Mostrar opción.
- Calcular faltante.
- Preparar solicitud.
- Explicar tiempo y certeza.

## Seguimiento

La vendedora debe recibir cambios relevantes.
