# Reglas por línea

## Remate Ocasión

- No se resurte.
- No se balancea.
- Si tienda y CEDIS quedan en cero, debe retirarse o revisarse para merma.
- Debe marcarse claramente en layout y comercialización.

## Ocasión Lujo

- Se considera resurtible.
- Puede balancearse si existe stock y cumple condiciones.

## Impulso

- Puede requerir prioridad por comercialización.
- La línea es temporal y debe leerse nuevamente cada mes.

## Producto Nuevo

- Puede requerir prioridad de exhibición y abastecimiento.

## Regla

La PWA no debe usar la palabra genérica `Ocasión` para decidir.
Debe trabajar con el nombre exacto de la línea.
