# Prompt de interfaz

Construye la pantalla indicada siguiendo Pack 15.

Incluye:

- Móvil.
- Escritorio.
- Carga.
- Vacío.
- Error.
- Sin permiso.
- Accesibilidad.
- Acción principal.
- Estados.
- Componentes reutilizados.
- Datos reales o contratos tipados.

No uses datos inventados como solución final.
