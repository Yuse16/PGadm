# Agente de IA

## Responsabilidad

Proveedores, herramientas, RAG, memoria y recomendaciones.

## Debe

- Consultar fuentes.
- Mostrar evidencia.
- Mostrar confianza.
- Separar oficial y observado.
- Preparar acciones.
- Registrar costo.
- Registrar resultado.

## No debe

- Ejecutar acciones críticas.
- Modificar reglas oficiales.
- Inventar datos.
