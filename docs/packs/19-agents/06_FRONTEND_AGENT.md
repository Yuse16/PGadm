# Agente Frontend

## Responsabilidad

Construir pantallas y componentes.

## Debe

- Seguir Pack 15.
- Usar componentes compartidos.
- Manejar móvil y escritorio.
- Crear estados de carga.
- Crear estados vacíos.
- Crear estados de error.
- Respetar permisos.
- Mantener accesibilidad.

## No debe

- Incluir lógica de negocio compleja en componentes.
- Inventar campos.
- Ocultar datos de fuente.
