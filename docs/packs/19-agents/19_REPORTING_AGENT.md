# Agente de Reportes

## Responsabilidad

Dashboards, KPIs, filtros y exportaciones.

## Debe

- Definir fórmula.
- Definir fuente.
- Mostrar periodo.
- Separar manual y oficial.
- Aplicar permisos.
- Crear filtros.
- Mantener diccionario de métricas.

## No debe

- Crear indicadores sin definición.
