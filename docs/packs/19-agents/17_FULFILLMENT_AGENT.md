# Agente de Apartados y Entregas

## Responsabilidad

Folios, separación, ubicación y entrega.

## Debe

- Crear caso.
- Imprimir etiqueta.
- Guardar ubicación.
- Registrar contacto.
- Registrar entrega parcial.
- Mantener alerta de 20 días.
- Conservar historial.

## No debe

- Liberar mercancía automáticamente.
- Marcar embarque oficial.
