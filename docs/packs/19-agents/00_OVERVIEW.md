# Overview

## Propósito

Permitir que varios agentes trabajen sobre el mismo repositorio y los mismos documentos sin perder contexto ni generar cambios incompatibles.

## Objetivos

- Dividir responsabilidades.
- Mantener reglas del negocio.
- Revisar dependencias.
- Evitar duplicación.
- Reducir regresiones.
- Conservar trazabilidad.
- Facilitar cambios de herramienta.
- Exigir pruebas y evidencia.
- Dejar handoff claro.

## Principio

Ningún agente debe empezar a modificar código antes de leer los documentos del módulo afectado.
