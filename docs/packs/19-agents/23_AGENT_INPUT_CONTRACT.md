# Contrato de entrada para agentes

## Toda petición debe incluir

- Objetivo.
- Módulo.
- Problema.
- Alcance.
- Fuera de alcance.
- Documentos.
- Dependencias.
- Restricciones.
- Criterios.
- Pruebas.
- Rama.
- Versión.

## Regla

Si falta información crítica, el agente debe detener la implementación y registrar la duda.
