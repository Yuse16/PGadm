# Recuperación ante fallo de agente

## Casos

- Cambio incompleto.
- Código roto.
- Handoff ausente.
- Migración fallida.
- Archivos no relacionados modificados.
- Pruebas no ejecutadas.

## Acción

- Detener.
- Revisar diff.
- Restaurar rama estable.
- Identificar cambio válido.
- Crear nueva tarea de recuperación.
- Documentar.
