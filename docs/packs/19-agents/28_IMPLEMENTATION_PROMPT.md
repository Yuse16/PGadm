# Prompt de implementación

Implementa únicamente la historia indicada.

Requisitos:

- Respeta el plan aprobado.
- Reutiliza componentes y servicios.
- Aplica permisos en servidor.
- Agrega validación.
- Agrega auditoría cuando aplique.
- Maneja carga, vacío y error.
- Agrega pruebas.
- Ejecuta pruebas.
- No modifiques módulos fuera de alcance.
- Entrega resumen completo.
