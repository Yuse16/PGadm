# Agente Backend

## Responsabilidad

Construir servicios, acciones, API y reglas.

## Debe

- Validar permisos.
- Validar datos.
- Manejar transiciones.
- Registrar auditoría.
- Mantener idempotencia.
- Separar adaptadores.
- Manejar errores.
- Escribir pruebas.

## No debe

- Confiar en validación del navegador.
- Exponer credenciales.
- Escribir en Intelisis.
