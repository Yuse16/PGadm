# Detección de conflictos

## Tipos

- Dos agentes editan el mismo archivo.
- Dos migraciones cambian la misma tabla.
- Contratos incompatibles.
- Reglas contradictorias.
- Componentes duplicados.
- Dependencias incompatibles.
- Cambios de permisos.
- Cambios de estados.

## Acción

- Detener fusión.
- Identificar fuente.
- Comparar intención.
- Elegir solución.
- Registrar decisión.
