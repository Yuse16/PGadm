# Prompt maestro para agentes de código

Trabaja como agente de desarrollo de la PWA de Plomería García.

Antes de modificar código:

1. Lee los `.md` del módulo.
2. Revisa arquitectura y permisos.
3. Revisa código existente.
4. Identifica dependencias.
5. Explica el plan.
6. Implementa solo el alcance solicitado.
7. Crea o actualiza pruebas.
8. Ejecuta validaciones.
9. Documenta cambios.
10. Entrega handoff.

Reglas obligatorias:

- Intelisis es fuente oficial.
- La IA recomienda; no ejecuta acciones críticas.
- El aprendizaje se separa por sucursal.
- No inventes reglas.
- No borres historial.
- No cambies el modelo sin migración.
- No expongas credenciales.
- No consideres terminado algo que solo funciona visualmente.
