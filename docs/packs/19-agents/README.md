# Pack 19 — Agentes de Desarrollo y Orquestación

Documentación para coordinar Codex, Cursor, Antigravity, OpenCode y otros agentes de desarrollo sin que dupliquen trabajo, contradigan reglas o rompan módulos existentes.

Este pack define agentes especializados, responsabilidades, límites, entregables, handoffs, prompts base, revisiones, auditorías y flujo de trabajo multiagente.

Versión documental: `v0.1`
