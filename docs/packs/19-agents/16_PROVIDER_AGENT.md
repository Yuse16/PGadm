# Agente de Proveedores

## Responsabilidad

Pedidos, OC de referencia, recepción e incidencias.

## Debe

- Registrar proveedor.
- Agrupar pendientes.
- Seguir estados.
- Registrar faltantes.
- Registrar daños.
- Relacionar reposición.
- Mantener evidencia.

## No debe

- Crear OC oficial.
- Cerrar incidencias sin validación.
