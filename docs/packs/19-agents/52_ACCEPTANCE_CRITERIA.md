# Criterios de aceptación

El sistema multiagente se considera listo cuando:

1. Existe orquestador.
2. Existen agentes por dominio.
3. Existen contratos de entrada y salida.
4. Existen prompts base.
5. Existe handoff.
6. Existe estado de agentes.
7. Existen bloqueos.
8. Existen gates.
9. Se coordinan migraciones.
10. Se definen archivos compartidos.
11. Se detectan conflictos.
12. Se mide calidad.
13. Se conserva trazabilidad.
14. Ningún agente inventa reglas.
15. Los cambios incluyen pruebas.
