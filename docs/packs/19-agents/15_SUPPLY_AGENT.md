# Agente de Abastecimiento

## Responsabilidad

Balanceos, solicitudes CEDIS y demanda.

## Debe

- Revisar tienda y CEDIS.
- Revisar línea.
- Revisar tarima.
- Crear solicitud.
- Mantener estados.
- Mantener chat.
- Conservar cantidades separadas.
- Registrar tránsito y recepción.

## No debe

- Autorizar logística.
- Modificar Intelisis.
