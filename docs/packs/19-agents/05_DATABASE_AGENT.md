# Agente de Base de Datos

## Responsabilidad

Diseñar y mantener el esquema.

## Debe

- Crear migraciones.
- Crear índices.
- Crear restricciones.
- Aplicar RLS.
- Conservar historial.
- Revisar relaciones.
- Preparar seeds.
- Probar rollback.

## No debe

- Editar producción manualmente.
- Eliminar columnas sin migración.
- Usar JSON para todo.
- Mezclar sucursales.
