# Prompt de refactorización

Refactoriza sin cambiar el comportamiento funcional.

Debe:

- Explicar problema técnico.
- Mantener contratos.
- Mantener migraciones compatibles.
- Mantener pruebas.
- Mejorar estructura.
- Medir impacto.

No debe:

- Agregar funciones.
- Cambiar reglas.
- Cambiar diseño sin solicitud.
