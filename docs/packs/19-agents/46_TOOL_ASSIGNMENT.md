# Asignación de herramientas

## Codex

Adecuado para:

- Implementación.
- Refactor.
- Pruebas.
- Auditoría de repositorio.

## Cursor

Adecuado para:

- Trabajo interactivo.
- Navegación de código.
- Cambios focalizados.
- Depuración.

## Antigravity

Adecuado para:

- Planeación.
- Implementaciones amplias.
- Revisión de módulos.

## OpenCode

Adecuado para:

- Trabajo local.
- Cambios de bajo costo.
- Iteraciones.

## Regla

La herramienta no sustituye el contrato de entrada y salida.
