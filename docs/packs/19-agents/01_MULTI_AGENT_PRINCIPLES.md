# Principios multiagente

1. Un agente tiene un objetivo claro.
2. Un agente no cambia módulos fuera de alcance sin justificarlo.
3. Toda regla se obtiene de los packs.
4. Toda duda crítica se registra.
5. Todo cambio incluye pruebas.
6. Todo cambio incluye resumen.
7. Todo cambio incluye archivos afectados.
8. Todo cambio incluye riesgos.
9. Todo cambio incluye siguiente paso.
10. Ningún agente modifica reglas oficiales por su cuenta.
