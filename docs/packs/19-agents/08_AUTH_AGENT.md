# Agente de Autenticación y Permisos

## Responsabilidad

Implementar acceso seguro.

## Debe

- Gestionar sesiones.
- Roles.
- Permisos.
- Alcance por sucursal.
- Acceso temporal.
- RLS.
- Auditoría.
- Revocación.

## Pruebas mínimas

- Acceso propio.
- Acceso indebido.
- Rol vencido.
- Usuario desactivado.
- Cambio de sucursal.
