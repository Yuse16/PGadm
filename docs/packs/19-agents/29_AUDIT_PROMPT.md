# Prompt de auditoría

Revisa el módulo sin modificarlo inicialmente.

Evalúa:

- Lógica.
- Permisos.
- Seguridad.
- Modelo de datos.
- Integraciones.
- Estados.
- Manejo de errores.
- Pruebas.
- Rendimiento.
- Accesibilidad.
- Coherencia con los `.md`.

Entrega hallazgos por severidad y evidencia.
