# Jerarquía de agentes

## Nivel 1 — Orquestador

Coordina el trabajo completo.

## Nivel 2 — Arquitectura

Protege estructura, contratos y dependencias.

## Nivel 3 — Agentes de dominio

Trabajan por módulo:

- Ventas.
- Inventario.
- Layout.
- CRM.
- Comercialización.
- CEDIS.
- Proveedores.
- Apartados.
- IA.
- Reportes.

## Nivel 4 — Calidad

Revisa pruebas, seguridad, accesibilidad y regresiones.

## Nivel 5 — Documentación

Actualiza decisiones, changelog y handoff.
