# Navegación en escritorio

## Estructura

- Barra lateral fija.
- Encabezado superior.
- Área de contenido.
- Panel lateral contextual.
- Centro de notificaciones.
- Selector de sucursal.

## Barra lateral

Debe permitir:

- Icono.
- Nombre.
- Estado activo.
- Submenús.
- Colapsar.
- Mostrar notificaciones.

## Regla

La navegación no debe cubrir el contenido.
