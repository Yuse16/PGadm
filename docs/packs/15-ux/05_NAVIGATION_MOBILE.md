# Navegación en móvil

## Estructura sugerida

Barra inferior con cinco accesos:

- Inicio.
- Buscar.
- Ventas.
- Tareas.
- Más.

## Menú Más

- Inventario.
- Layout.
- Comercialización.
- Clientes.
- CEDIS.
- Juntas.
- Reportes.
- Configuración.

## Regla

La búsqueda debe estar siempre a un toque.
