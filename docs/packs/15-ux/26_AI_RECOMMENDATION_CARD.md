# Tarjeta de recomendación IA

## Contenido

- Acción sugerida.
- Motivo.
- Prioridad.
- Confianza.
- Datos usados.
- Fecha.
- Riesgo.
- Alternativas.

## Botones

- Revisar.
- Preparar.
- Aceptar.
- Modificar.
- Rechazar.
- Ver evidencia.

## Regla

Nunca mostrar una recomendación importante sin explicación.
