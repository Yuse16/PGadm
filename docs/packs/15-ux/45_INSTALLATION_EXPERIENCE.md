# Instalación PWA

## Flujo

- Detectar compatibilidad.
- Mostrar beneficio.
- Explicar instalación.
- Confirmar.
- Abrir aplicación.
- Mostrar onboarding.

## Beneficios visibles

- Acceso rápido.
- Pantalla completa.
- Notificaciones.
- Uso parcial offline.

## Regla

No bloquear el uso web si el usuario no instala.
