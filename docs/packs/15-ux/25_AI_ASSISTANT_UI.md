# Interfaz del asistente de IA

## Accesos

- Botón global.
- Panel lateral.
- Chat dentro de módulo.
- Acciones rápidas.

## Contexto visible

La IA debe mostrar:

- Sucursal.
- Módulo.
- Fuentes.
- Fecha.
- Nivel de confianza.

## Acciones

- Preguntar.
- Ver evidencia.
- Aplicar como borrador.
- Rechazar.
- Corregir.
