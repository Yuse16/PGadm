# Analítica de experiencia

## Eventos

- Búsqueda.
- Producto abierto.
- Calculadora usada.
- Cotización creada.
- Seguimiento completado.
- Error.
- Abandono.
- Tiempo por tarea.
- Acción IA aceptada.

## Objetivo

Detectar pasos lentos o confusos.

## Privacidad

No registrar datos sensibles innecesarios.
