# Overview

## Propósito

Crear una interfaz rápida, clara y útil para personas que trabajan en piso de venta, almacén, oficina, CEDIS y Comercial.

## Principio central

La PWA debe reducir pasos y tiempo.

Un usuario debe encontrar lo importante sin recorrer múltiples pantallas ni conocer la estructura interna del sistema.

## Prioridades

- Mobile first para vendedores y almacén.
- Escritorio para layout, reportes y administración.
- Botones grandes.
- Búsqueda inmediata.
- Información contextual.
- Estados visibles.
- Menos texto, más acción.
- Consistencia entre módulos.
