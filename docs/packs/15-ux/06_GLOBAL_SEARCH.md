# Búsqueda global

## Debe encontrar

- Productos.
- Códigos.
- Clientes.
- Folios.
- Cotizaciones.
- Solicitudes.
- Juntas.
- Ubicaciones.
- Proveedores.
- Tareas.

## Resultado

Cada resultado debe mostrar:

- Tipo.
- Nombre.
- Código o referencia.
- Sucursal.
- Estado.
- Acción principal.

## Regla

Priorizar coincidencias exactas.
