# Objetivos de experiencia

## Vendedora

- Buscar producto en segundos.
- Calcular proyecto.
- Cotizar.
- Ver stock.
- Dar seguimiento.
- Saber qué hacer hoy.

## Gerente

- Ver prioridades.
- Editar layout.
- Revisar comercialización.
- Consultar ventas.
- Aprobar acciones.

## Almacén

- Encontrar folio.
- Separar mercancía.
- Registrar recepción.
- Imprimir etiqueta.
- Confirmar entrega.

## CEDIS

- Revisar solicitudes.
- Responder cantidades.
- Ver demanda.
- Actualizar tránsito.
