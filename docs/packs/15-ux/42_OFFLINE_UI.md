# Interfaz sin conexión

## Debe mostrar

- Estado offline.
- Última sincronización.
- Funciones disponibles.
- Cambios pendientes.
- Conflictos.

## Acciones permitidas

- Consultar caché.
- Crear borradores.
- Registrar notas.
- Preparar cotización.
- Tomar evidencias.

## Regla

No presentar stock en caché como actual.
