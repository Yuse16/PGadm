# Criterios de aceptación

La experiencia se considera lista cuando:

1. La navegación cambia por rol.
2. La búsqueda está a un toque.
3. El layout permite zoom y panel contextual.
4. M1 muestra rieles y posiciones.
5. Las acciones críticas tienen confirmación.
6. Los datos muestran fuente y fecha.
7. Funciona en móvil y escritorio.
8. No depende solo de color.
9. Tiene estados de carga, vacío y error.
10. Conserva borradores.
11. Permite uso offline parcial.
12. La IA muestra evidencia y confianza.
13. Existe biblioteca de componentes.
14. Se puede instalar como PWA.
15. Cumple accesibilidad básica.
