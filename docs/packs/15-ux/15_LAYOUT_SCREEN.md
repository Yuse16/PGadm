# Pantalla de layout

## Vista principal

- Plano completo.
- Zoom.
- Paneo.
- Capas.
- Leyenda.
- Buscador.
- Modo edición.
- Filtros.

## Al tocar un mueble

- Acercar.
- Resaltar.
- Abrir panel lateral.
- Mostrar productos.
- Mostrar stock.
- Mostrar alertas.
- Mostrar acciones.

## Regla

El layout debe ser un mapa estructurado, no una imagen plana.
