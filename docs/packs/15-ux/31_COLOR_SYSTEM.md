# Sistema de color

## Categorías

- Fondo.
- Superficie.
- Texto.
- Primario.
- Secundario.
- Éxito.
- Advertencia.
- Error.
- Información.
- Promoción.

## Layout

Los colores del mapa deben ser configurables y acompañarse de iconos o etiquetas.

## Regla

Los colores de líneas comerciales no deben confundirse con estados del sistema.
