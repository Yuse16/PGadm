# Pack 15 — UX, UI y Sistema de Diseño

Documentación funcional y visual para diseñar la experiencia de uso de la PWA de Plomería García en teléfono, tableta y computadora.

Este pack define navegación, pantallas, componentes, estados, layout interactivo, accesibilidad, modo móvil, modo escritorio y criterios de consistencia visual.

Versión documental: `v0.1`
