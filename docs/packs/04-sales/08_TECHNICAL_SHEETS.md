# Fichas técnicas

## Objetivo

Mostrar la ficha técnica exacta del producto consultado.

## Fuentes

1. Página oficial de Plomería García.
2. Ficha oficial del fabricante.
3. Documento interno validado.
4. Intelisis, cuando contenga datos.

## Campos posibles

- Código.
- Marca.
- Modelo.
- Formato.
- Color.
- Acabado.
- Rectificado.
- Antiderrapante.
- Absorción.
- Uso interior.
- Uso exterior.
- Uso comercial.
- Tráfico.
- Piezas por caja.
- m² por caja.
- Boquilla mínima.
- Recomendaciones de instalación.
- Garantía.
- Documentos descargables.

## Regla

La ficha debe relacionarse por código exacto.

No debe asignarse una ficha similar por nombre.
