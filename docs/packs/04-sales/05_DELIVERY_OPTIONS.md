# Opciones de entrega

## Estados comerciales

- Entrega inmediata en tienda.
- Disponible para envío a domicilio.
- Disponible en CEDIS.
- Requiere balanceo.
- Requiere pedido a proveedor.
- Existencia insuficiente.
- Pendiente de confirmar.

## Regla

La PWA no debe prometer una fecha sin respaldo.

## Información para cliente

- Lugar de origen.
- Cantidad disponible.
- Tiempo estimado.
- Tipo de entrega.
- Nivel de certeza.
- Observaciones.
