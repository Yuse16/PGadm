# Pack 04 — Ventas

Documentación funcional del módulo comercial y de ventas para la PWA de Plomería García.

Este pack define cómo la aplicación debe ayudar a vender más rápido, cotizar mejor, aprovechar el stock de tienda y CEDIS, recomendar productos cercanos a lo solicitado por el cliente y dar seguimiento hasta el cierre.

Versión documental: `v0.1`
