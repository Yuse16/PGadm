# Postventa

## Acciones

- Confirmar entrega.
- Recordar revisión de mercancía.
- Registrar incidencia.
- Solicitar fotografía del proyecto.
- Pedir recomendación.
- Ofrecer complemento faltante.
- Registrar satisfacción.

## Objetivo

Convertir una venta en relación de largo plazo y nuevas oportunidades.
