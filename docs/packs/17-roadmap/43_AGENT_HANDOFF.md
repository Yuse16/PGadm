# Entrega entre agentes

## Antes de cambiar de agente

El agente actual debe registrar:

- Objetivo trabajado.
- Cambios.
- Archivos.
- Migraciones.
- Pruebas.
- Pendientes.
- Errores conocidos.
- Próximo paso.
- Commit.

## El siguiente agente debe

- Leer documentación.
- Revisar cambios.
- Ejecutar pruebas.
- Confirmar estado.
- No duplicar trabajo.
