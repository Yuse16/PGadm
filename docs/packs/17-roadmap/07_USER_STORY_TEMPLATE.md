# Plantilla de historia

## Formato

Como `[rol]`, necesito `[acción]`, para `[resultado]`.

## Debe incluir

- ID.
- Contexto.
- Reglas.
- Datos.
- Permisos.
- Criterios de aceptación.
- Estados de error.
- Pruebas.
- Dependencias.
- Archivos afectados.
- Documentos fuente.

## Regla

No comenzar historias con criterios ambiguos.
