# Sistema de prioridad

## P0 — Crítica

Bloquea venta, seguridad, datos o producción.

## P1 — Alta

Necesaria para el flujo principal.

## P2 — Media

Mejora importante con alternativa disponible.

## P3 — Baja

Optimización o comodidad.

## Regla

No confundir urgencia solicitada con impacto real.
