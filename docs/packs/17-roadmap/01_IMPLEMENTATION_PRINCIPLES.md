# Principios de implementación

1. Construir primero la base compartida.
2. No desarrollar módulos aislados sin contratos.
3. Crear migraciones antes de depender de datos.
4. Aplicar permisos desde la primera versión.
5. Mantener los datos separados por sucursal.
6. Conservar historial desde el inicio.
7. Probar cálculos y estados antes de diseñar dashboards.
8. Crear adaptadores para integraciones.
9. Liberar por fases.
10. No conectar directamente a Intelisis sin autorización.
