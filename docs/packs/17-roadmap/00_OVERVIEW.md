# Overview

## Propósito

Transformar la visión y reglas del proyecto en trabajo técnico ordenado.

## Objetivos

- Evitar que distintos agentes construyan módulos incompatibles.
- Definir qué debe hacerse primero.
- Separar MVP, piloto y expansión.
- Mantener trazabilidad entre reglas, historias y código.
- Reducir retrabajo.
- Facilitar auditorías.
- Permitir cambios de agente sin perder contexto.

## Principio

Cada tarea debe indicar:

- problema,
- alcance,
- dependencias,
- criterios de aceptación,
- archivos relacionados,
- pruebas requeridas.
