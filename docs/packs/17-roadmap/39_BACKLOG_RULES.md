# Reglas del backlog

## Cada elemento debe

- Tener ID.
- Tener prioridad.
- Tener módulo.
- Tener responsable.
- Tener estado.
- Tener documentos fuente.
- Tener dependencias.
- Tener criterios.
- Tener versión objetivo.

## Estados

- Idea.
- Refinamiento.
- Lista.
- En desarrollo.
- En revisión.
- En pruebas.
- Hecha.
- Bloqueada.
