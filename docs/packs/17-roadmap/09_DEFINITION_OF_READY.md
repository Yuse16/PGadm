# Definición de listo para desarrollar

Una historia está lista cuando:

- El problema está claro.
- El usuario está definido.
- El alcance está delimitado.
- Las dependencias están disponibles.
- Los permisos están definidos.
- Los datos están modelados.
- Los estados están definidos.
- Los criterios son verificables.
- Los documentos fuente están enlazados.
- No existen dudas críticas.
