# Reglas para agentes de código

1. Leer los `.md` relacionados.
2. Revisar arquitectura existente.
3. No reemplazar módulos completos sin necesidad.
4. No borrar historial.
5. No inventar reglas.
6. No agregar dependencias sin justificar.
7. Crear migraciones.
8. Agregar pruebas.
9. Documentar cambios.
10. Entregar resumen y commit sugerido.
