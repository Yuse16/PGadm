# Relación con cliente

## Objetivo

Mostrar qué cliente o venta depende de la compra o reposición.

## Datos

- Cliente.
- Vendedora.
- Cotización.
- Oportunidad.
- Producto.
- Cantidad.
- Fecha requerida.
- Valor potencial.
- Estado.

## Notificación

Cuando cambia la fecha o llega mercancía, la vendedora debe recibir aviso.
