# Contactos de proveedor

## Tipos

- Vendedor.
- Ejecutivo.
- Logística.
- Crédito y cobranza.
- Garantías.
- Atención a incidencias.
- Gerente.

## Campos

- Nombre.
- Cargo.
- Teléfono.
- WhatsApp.
- Correo.
- Horario.
- Canal preferido.
- Proveedores o marcas relacionados.

## Regla

No compartir datos de contacto fuera de perfiles autorizados.
