# Desempeño de proveedor

## Indicadores

- Tiempo de confirmación.
- Tiempo de entrega.
- Entregas completas.
- Entregas parciales.
- Incidencias.
- Daños.
- Faltantes.
- Tiempo de reposición.
- Casos sin respuesta.

## Regla

Los indicadores deben basarse en datos registrados y mostrar el periodo.
