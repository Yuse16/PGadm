# Reporte de daño

## Evidencia recomendada

- Producto completo.
- Acercamiento del daño.
- Etiqueta o código.
- Empaque.
- Factura.
- Orden.
- Cantidad afectada.

## Información

- Tipo de daño.
- Momento detectado.
- Responsable de recepción.
- Condición del transporte.
- Acción solicitada.

## Regla

No modificar ni desechar evidencia antes de completar el reporte, salvo indicación operativa.
