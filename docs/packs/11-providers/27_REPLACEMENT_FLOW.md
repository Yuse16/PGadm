# Flujo de reposición

## Datos

- Incidencia origen.
- Producto.
- Cantidad.
- Fecha prometida.
- Fecha enviada.
- Fecha recibida.
- Estado físico.
- Evidencia.
- Responsable.

## Regla

La reposición debe ligarse a la incidencia original.

No debe parecer una compra nueva si corresponde a una deuda del proveedor.
