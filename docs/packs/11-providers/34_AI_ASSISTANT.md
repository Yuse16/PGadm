# IA para proveedores y compras

## Puede

- Agrupar artículos.
- Sugerir proveedor.
- Preparar solicitud.
- Detectar retrasos.
- Resumir conversación.
- Preparar reporte.
- Identificar incidencias repetidas.
- Proponer seguimiento.
- Analizar cumplimiento.

## No puede

- Crear OC oficial.
- Aprobar compra.
- Confirmar mercancía.
- Alterar Intelisis.
- Cerrar incidencia sin validación.
