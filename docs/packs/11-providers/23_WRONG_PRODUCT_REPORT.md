# Producto incorrecto

## Casos

- Código diferente.
- Modelo diferente.
- Color diferente.
- Formato diferente.
- Marca diferente.
- Producto adicional no solicitado.

## Datos

- Producto ordenado.
- Producto recibido.
- Cantidad.
- Evidencia.
- Instrucción del proveedor.
- Devolución o reposición.
