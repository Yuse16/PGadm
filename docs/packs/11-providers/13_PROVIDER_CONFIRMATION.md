# Confirmación del proveedor

## Datos

- Fecha de confirmación.
- Contacto.
- Cantidad confirmada.
- Fecha prometida.
- Forma de entrega.
- Sustituciones propuestas.
- Observaciones.
- Evidencia.

## Regla

No considerar confirmado solo porque la solicitud fue enviada.

Debe existir respuesta o validación explícita.
