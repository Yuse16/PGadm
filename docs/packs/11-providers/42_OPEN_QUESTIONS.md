# Pendientes de alta prioridad

## Proceso

- Confirmar quién aprueba cada tipo de compra.
- Confirmar campos exactos de OC.
- Confirmar tiempos por categoría.
- Confirmar pedido mínimo por proveedor.
- Confirmar flujo de nota de crédito.

## Recepción

- Validar formalmente el proceso factura completa / faltante físico.
- Confirmar quién cierra una incidencia.
- Confirmar tratamiento de mercancía dañada.
- Confirmar evidencia obligatoria.

## Integraciones

- Correo.
- WhatsApp.
- Intelisis.
- Documentos de proveedor.
- Portal de compras.
