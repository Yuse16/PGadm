# Frecuencia del proveedor

## Datos

- Día habitual de visita.
- Día de toma de pedido.
- Día de entrega.
- Frecuencia semanal, quincenal o mensual.
- Tiempo de fabricación.
- Tiempo de traslado.
- Temporadas especiales.

## Uso

La IA puede considerar la frecuencia para recomendar:

- Esperar próxima visita.
- Preparar pedido.
- Aumentar cantidad.
- Escalar por retraso.

## Regla

La frecuencia observada debe diferenciarse de un compromiso confirmado.
