# Reglas de pedido mínimo

## Posibles restricciones

- Pieza completa.
- Caja completa.
- Paquete.
- Tarima.
- Monto mínimo.
- Modelo mínimo.
- Color mínimo.
- Combinación por familia.

## Comportamiento

La PWA debe mostrar:

- Necesidad real.
- Mínimo del proveedor.
- Cantidad sugerida.
- Excedente.
- Riesgo de inventario.

## Regla

No inventar mínimos faltantes.
