# Permisos

## Vendedora

- Crear necesidad ligada a cliente.
- Ver estado.
- Recibir notificaciones.

## Gerente

- Revisar solicitudes.
- Aprobar para captura.
- Ver órdenes.
- Crear incidencias.
- Dar seguimiento.

## Almacén

- Registrar recepción.
- Reportar daño.
- Reportar faltante.
- Confirmar reposición.

## Compras o Comercial

- Gestionar órdenes.
- Contactar proveedor.
- Registrar respuesta.
- Consultar indicadores.

## Administrador

- Configurar catálogos y permisos.
