# Aprobación

## Antes de aprobar

Debe verificarse:

- Producto exacto.
- Proveedor correcto.
- Cantidad.
- Unidad.
- Mínimo.
- Existencia tienda/CEDIS.
- Cliente relacionado.
- Fecha requerida.
- Riesgo.
- Evidencia.

## Registro

- Usuario.
- Fecha y hora.
- Decisión.
- Motivo.
- Cambios de cantidad.
