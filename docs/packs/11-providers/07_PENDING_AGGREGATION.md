# Agrupación de artículos pendientes

## Objetivo

Agrupar necesidades del mismo proveedor antes de crear una orden.

## Criterios

- Proveedor.
- Marca.
- Familia.
- Fecha límite.
- Cantidad mínima.
- Tarima.
- Cliente.
- Prioridad.

## Regla

La agrupación no debe ocultar el origen de cada cantidad.

Cada artículo conserva relación con:

- Cliente.
- Sucursal.
- Solicitud.
- Usuario.
- Fecha.
