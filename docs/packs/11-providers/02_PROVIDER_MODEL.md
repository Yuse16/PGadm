# Modelo de proveedor

## Campos

- Nombre comercial.
- Razón social.
- Código.
- Marcas.
- Familias.
- Contactos.
- Teléfonos.
- Correos.
- Canal habitual.
- Frecuencia de visita o entrega.
- Tiempo estimado.
- Condiciones de pedido.
- Cantidad mínima.
- Reglas de tarima.
- Estado.

## Estado

- Activo.
- Suspendido.
- En revisión.
- Inactivo.
