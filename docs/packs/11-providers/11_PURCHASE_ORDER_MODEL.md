# Modelo de orden de compra

## Campos

- Folio interno PWA.
- Folio Intelisis.
- Proveedor.
- Sucursal o almacén.
- Fecha.
- Solicitante.
- Capturista.
- Aprobador.
- Estado.
- Total estimado.
- Fecha prometida.
- Observaciones.

## Artículos

- Código.
- Descripción.
- Cantidad solicitada.
- Cantidad confirmada.
- Cantidad recibida.
- Unidad.
- Precio, si está permitido.
