# Comenzar aquí

## Orden recomendado

1. Leer este pack completo.
2. Revisar el índice de packs.
3. Confirmar decisiones pendientes.
4. Preparar repositorio y ambientes.
5. Ejecutar Sprint 0.
6. Implementar núcleo.
7. Cargar datos demo.
8. Construir MVP.
9. Probar en Nogalera.
10. Liberar por fases.

## Regla central

No comenzar por IA, dashboards o automatizaciones avanzadas antes de tener:

- usuarios,
- permisos,
- sucursales,
- productos,
- inventario,
- layout,
- auditoría,
- pruebas.
