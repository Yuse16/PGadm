# Criterios maestros

El proyecto documental está listo para desarrollo cuando:

1. Existe visión.
2. Existen módulos.
3. Existen reglas.
4. Existe arquitectura.
5. Existe modelo de datos.
6. Existen contratos.
7. Existen permisos.
8. Existe seguridad.
9. Existe roadmap.
10. Existen pruebas.
11. Existe migración.
12. Existe capacitación.
13. Existe piloto.
14. Existen agentes.
15. Existen decisiones pendientes identificadas.
