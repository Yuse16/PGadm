# Instrucción final para agentes

No intentes construir todo en una sola ejecución.

Trabaja por historia, conserva el contexto, protege la arquitectura y entrega resultados verificables.

El éxito no es producir muchos archivos.

El éxito es que cada flujo funcione de extremo a extremo, con datos confiables, permisos correctos, pruebas y una experiencia útil para la tienda.
