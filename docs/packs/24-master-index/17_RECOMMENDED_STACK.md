# Stack recomendado

## Aplicación

- Next.js.
- TypeScript.
- Tailwind CSS.
- PWA.

## Backend y datos

- Supabase.
- PostgreSQL.
- Storage privado.
- Row Level Security.

## Integraciones

- Excel inicial.
- Conector local posterior.
- SQL o cubos autorizados después.

## IA

- Adaptador de modelos.
- OpenRouter inicialmente.
- Proveedor separado para transcripción cuando sea necesario.

## Despliegue

- Vercel.
