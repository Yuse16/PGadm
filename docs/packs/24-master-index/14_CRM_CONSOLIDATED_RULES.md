# Reglas consolidadas de CRM

- Un cliente puede tener varios proyectos.
- Un proyecto puede tener varias oportunidades.
- Toda oportunidad abierta requiere siguiente acción.
- Toda pérdida requiere motivo.
- Las cotizaciones se relacionan con cliente y oportunidad.
- Los clientes esperando stock reciben seguimiento.
- La vendedora ve sus clientes; el gerente ve su tienda.
