# Reglas consolidadas de inventario

- Stock tienda y CEDIS se muestran separados.
- Cada dato muestra fecha.
- Cada carga crea snapshot.
- Los cambios se comparan entre snapshots.
- Sin cubo de movimientos, no se atribuye causa.
- No existe confirmación actual de reservado o backorder.
- Existencia reportada no equivale a disponibilidad garantizada.
