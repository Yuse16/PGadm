# Visión del proyecto

Construir una PWA operativa y comercial para Plomería García que conecte:

- vendedores,
- gerentes,
- almacén,
- CEDIS,
- Comercial,
- proveedores,
- clientes,
- inventario,
- layout,
- comercialización,
- ventas,
- inteligencia artificial.

La aplicación debe ayudar a vender mejor, responder más rápido, conservar conocimiento y convertir datos dispersos en acciones claras.
