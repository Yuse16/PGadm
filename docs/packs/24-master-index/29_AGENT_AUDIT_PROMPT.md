# Prompt de auditoría final

Audita el repositorio completo contra la documentación.

Revisa:

- arquitectura,
- permisos,
- RLS,
- datos,
- inventario,
- layout,
- ventas,
- CRM,
- comercialización,
- CEDIS,
- IA,
- seguridad,
- pruebas,
- móvil,
- rendimiento,
- despliegue.

Entrega hallazgos por severidad, evidencia, archivo y corrección recomendada.
