# Primer flujo vertical

## Objetivo

Demostrar arquitectura completa con un flujo pequeño.

## Flujo

1. Usuario inicia sesión.
2. Selecciona Nogalera.
3. Busca producto.
4. Ve stock tienda/CEDIS.
5. Abre ubicación en layout.
6. Calcula cajas.
7. Crea cotización.
8. Se registra auditoría.

## Beneficio

Valida frontend, backend, base, permisos y datos.
