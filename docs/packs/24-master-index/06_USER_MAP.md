# Mapa de usuarios

## Vendedora

Busca, calcula, cotiza, registra clientes y da seguimiento.

## Gerente

Supervisa ventas, layout, comercialización, inventario y aprobaciones.

## Almacén

Recibe, separa, etiqueta, entrega y reporta incidencias.

## CEDIS

Revisa solicitudes, cantidades, tránsito y demanda.

## Comercial

Compara sucursales, define campañas y revisa cumplimiento.

## Administrador

Gestiona usuarios, permisos, integraciones y seguridad.
