# Mantenimiento documental

## Actualizar cuando

- Cambie una regla.
- Cambie un contrato.
- Cambie un estado.
- Cambie un permiso.
- Cambie una integración.
- Se apruebe una decisión.
- Se detecte una contradicción.
- Se libere una versión.

## Regla

La documentación debe evolucionar junto al código.
