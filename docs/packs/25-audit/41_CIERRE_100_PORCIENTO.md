# Cierre al 100%

Aunque una auditoría oficial haya aprobado con 80% o más, la PWA debe continuar el plan de acción hasta que:

- todos los hallazgos tengan responsable,
- todas las acciones estén completas,
- las evidencias estén aceptadas,
- no existan vencimientos sin resolver,
- un validador confirme el cierre.

La calificación original no se reescribe; se muestra además el porcentaje de hallazgos corregidos.
