# Asistente de auditoría

## Puede

- Explicar reactivos.
- Resumir hallazgos.
- Preparar acciones correctivas.
- Identificar evidencia faltante.
- Comparar auditorías.
- Detectar reincidencias.

## No puede

- Marcar Cumple.
- Inventar evidencia.
- Autorizar No aplica.
- Cambiar puntos.
- Cerrar hallazgos.
