# Roles y permisos

Todos los usuarios autorizados pueden consultar y registrar progreso según su alcance.

## Gerente y subgerente

- Crear preauditoría.
- Asignar responsables.
- Validar avances.
- Solicitar corrección.

## Auditor

- Aplicar auditoría oficial.
- Calificar.
- Registrar comentarios.
- Validar cierre.

## Administrador

- Versionar plantillas.
- Gestionar preguntas, puntos y permisos.

Las acciones se controlan por permiso y sucursal.
