# Pruebas

## Puntuación

- Todo Cumple.
- Todo Fallo.
- No aplica autorizado.
- Resultado exactamente 80%.
- Módulo sin puntos aplicables.

## Flujo

- Crear preauditoría.
- Fallar reactivo.
- Generar hallazgo.
- Asignar responsable.
- Subir evidencia.
- Rechazar y corregir.
- Validar y cerrar.

## Seguridad

- Usuario de otra sucursal.
- Usuario sin permiso de cierre.
- Auditoría cerrada.
- Cambio de plantilla.
