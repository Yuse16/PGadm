# Plan de acción

Cada hallazgo debe tener al menos una acción con:

- descripción,
- responsable,
- participantes,
- fecha de inicio,
- fecha compromiso,
- evidencia esperada,
- porcentaje de avance,
- comentarios,
- validación final.

El avance no cambia la calificación hasta que el reactivo sea validado como Cumple.
