# Tareas y alertas

Cuando un reactivo falla, la PWA puede preparar una tarea con responsable, prioridad, fecha y evidencia requerida.

## Alertas

- Hallazgo sin responsable.
- Fecha próxima.
- Fecha vencida.
- Evidencia rechazada.
- Módulo menor a 80%.
- Reincidencia.
- Auditoría próxima.

Las acciones sugeridas por IA requieren confirmación humana.
