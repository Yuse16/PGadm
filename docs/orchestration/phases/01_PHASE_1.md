# Primera instrucción para pegar en OpenCode

Lee todos los `.md` de la raíz, este paquete de orquestación y los packs `00–25`.

No modifiques código todavía.

1. Verifica `git status`, rama y `git remote -v`.
2. Confirma si `origin` corresponde a `Yuse16/PGadm`.
3. Inventaría código y documentación.
4. Detecta si ya existe aplicación.
5. Detecta cambios locales sin commit.
6. Crea mapa de módulos, dependencias y riesgos.
7. Propón la ejecución exacta de Fase 0.
8. Indica ramas y worktrees.
9. Indica agentes participantes.
10. Espera aprobación antes de acciones destructivas o push.
