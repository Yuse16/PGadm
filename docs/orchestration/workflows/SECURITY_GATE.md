# Pull requests

## Flujo

Agente → rebase → pruebas → push → PR a `develop` → QA → Seguridad/Arquitectura cuando aplique → Orquestador.

## Debe incluir

Objetivo, historia, packs, cambios, capturas, migraciones, pruebas, riesgos, rollback y pendientes.

No integrar con pruebas fallidas, sin RLS, sin migración o con secretos.
