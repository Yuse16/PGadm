# Plomería García PWA — Base de conocimiento

Documentación funcional para construir una PWA que conecte layout, inventario, comercialización, ventas, CEDIS, juntas e inteligencia artificial.

## Principio central
Reducir el tiempo operativo para aumentar el tiempo dedicado a vender.

## Reglas base
- Intelisis es la fuente oficial.
- La PWA complementa a Intelisis; no lo sustituye.
- La IA recomienda y explica; el usuario autorizado decide.
- Las reglas oficiales no se modifican automáticamente.
